# 已知视觉差异与验证边界

1. 独立 HTML 是原创渲染器，不是 SP 原生渲染器。结构校验不能证明原生显示、导入交互或保存成功。
2. 未打包 Inter / 中文字体。Arial、Noto Sans CJK SC 与系统 sans/mono 回退可能改变字宽、行高和换行；不同机器需复核。
3. 底层 text/shape 均可编辑，但表格和条形图采用独立文本/矩形对象，不具备原生数据表格、图表自动重算或联动。
4. HTML 的 180ms 入场不会进入 canonical 动画；上游路由、搜索、悬停、抽屉和地图缩放不属于演示文稿。
5. 12px圆角、1px描边及字体字重在原生SP导入后需要逐页确认；adapter模型往返保留字段并不证明渲染支持。
6. 预览文字编辑器只编辑文字。调整数字不会自动修改柱条长度；需同步修改 JSON 几何或 build.mjs。
7. 预览窄屏等比缩放画布，维持16:9构图，不将演示重排成移动网页；正文可能较小，可放大。
8. 没有原生SP导入验收，没有PPTX导出验收；保持三级参考，不升为全适配。
