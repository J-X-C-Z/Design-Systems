# Design Systems 风格目录

静态中文画廊，网页入口 `index.html`。下载整个仓库后，在仓库根目录运行 `python3 -m http.server 8000 --bind 127.0.0.1`，浏览器打开 http://127.0.0.1:8000/web/ 。不需要安装依赖或构建；网页和样例由本机静态服务读取，公共仓库未启用 GitHub Pages。页面提供桌面及手机响应布局规则，支持搜索、来源/等级过滤、独立三方参考、隔离样例预览及来源/待完成项详情。

## 数据与资源

`catalog.json` 与归档 `classification/catalog.json` 原样一致，是分类唯一来源。`catalog-data.js` 为同一 JSON 的 JavaScript 包装，使目录在直接打开 HTML 时也能使用。更新时必须同步生成，不能独立手改分类。

10 套语言有原始可运行样例；12 套 Batch 02 研究档案没有本地样例。14 项成熟三方精选展示完整规则、资源及许可，172 个原始三方 URL 收入独立可折叠索引。14项中7项增强已有参考、7项为新增独立资源，两者不相加为总风格数，均不计为本地语言。人工精修仅 MiMo v2.0。当前一级 0、二级 10、三级语言 12。

仓库版直接引用 `../languages/` 和 `../research/` 的原始资料，保留全部相对依赖和证据，不在 `web/` 重复保存语言副本，MiMo 继续只有一个规范目录。静态服务的根目录须为仓库根目录；只复制 `web/` 会缺少样例。MiMo 和瑞士预览使用其原有截图；其余使用实际 HTML 的隔离 iframe。iframe 只授权脚本、不授予同源、弹窗、表单或顶层导航。点击“运行样例”可单独打开原始 HTML。没有修改或提升任何设计语言本体。

## 验证范围

在 `web/` 目录运行 `node --check app.js`、`node verify.cjs`、`node verify-reviews.cjs` 和 `node verify-collections.cjs`。18 项筛选/详情/初始星级及相对目标检查、20 项评价迁移/存储保护检查、6 项三方资源筛选检查使用模拟 DOM／隔离存储（包含全部22项详情及14项精选参考），不代表真实浏览器渲染。仓库合入时另核对本地样例/验收/研究目标、相对链接和共享分类数据一致性；原始语言资料保持逐字节不变。

当前执行环境 Chromium 启动因 socket 权限失败，未完成本轮真实浏览器桌面/手机截图、布局及交互 QA。CSS 包含 1000px / 650px 响应断点，但不能以静态检查替代真实设备验收。原档验收边界继续保留，目录上线不改变语言成熟度。

## 评分与新增三方资源

原十项“差”按用户指令一次性迁移为初始一星，历史保留；卡片可直接打星、另写评语。仅当前浏览器 localStorage 保存，32 个评价对象为 22 语言和 10 候选；候选首页展示区移除，评价管理器及备份仍保留。后续改星不复位，迁移保留评语与其他对象。需要跨浏览器迁移时自行导出 JSON；代码不读取其他设备数据。

reference-collections.html 展示 Dashi 12 主题及 Watermelon 1 平台＋18 子资源，合计 31 个参考条目，不改变本地 22 语言和等级。支持平台、类型和搜索筛选；只原创摘要与外部官方链接，不嵌入上游程序或下载图片。

公共仓库未含云网站其他精修包，继续保留 10 原始样例／12 研究方向；未合入缺少资源的精修声明。主页精修说明和候选卡片区移除，规范、研究和所有候选仍在原目录。部署身份不公开。原云网站 QA 记录与公共仓库整合检查范围见 ../research/third-party/INCREMENT_NOTES.md。
