# Public Dashi branch archive scope

This branch contains 12 static HTML theme previews, original fictional content, adapter source and source-calibrated SP sample JSON. The original supplied QA is historical evidence; this upload does not repeat desktop/mobile browser acceptance. Native SP import, editing, save/reopen and PPTX fidelity remain unverified.

The public conversion source ZIP deliberately excludes all vendor-work entries. Original adapters still refer to those omitted build dependencies; this reduced archive is not a standalone rebuild kit. SP-SOURCE-ONLY-REPRODUCTION.json describes the original fuller isolated input, not reproducibility of this reduced public ZIP. No removed modules were renamed to bypass the exclusion.

Excluded: vendor-work, sp-validation, minified upstream runtime, proprietary PPTX components, unlicensed SP product source, old split 8+4 packages, private deployment identity, credentials and internal QA screenshots. Layout-query text and its theme11 patch are retained as the explicitly provided source/attribution record under AGPL-3.0.

AGPL LICENSE and source notices are retained; no claim of complete preferred upstream JSX source or runtime redistribution clearance is made.
