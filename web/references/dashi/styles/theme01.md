# 轻拟态风（theme01）

作者：chuspeeism；三方参考；等级3，仅确认方向。

浅蓝灰底承托柔和白色面板，圆角与双向柔影突出轻量产品汇报。

## 可辨识规则
- 浅色低饱和底与蓝绿重点
- 较大圆角、柔影和半透明面板
- 常规无衬线配合模块化指标布局

## 场景
产品介绍 / 企业汇报 / 方案说明 / 轻量级发布。

## 现有库关系
关联ID：mimo, batch02-01。

与 MiMo/Material 的柔性卡片存在表面相似；其核心用途是 PPT 版式，并非应用组件规范。

## 成熟资料
固定版本 metadata.js 实际登记 84 个页面；对应 theme-runtime 模块、主题配置与官方预览资源均存在。
