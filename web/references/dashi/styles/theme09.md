# 深蓝杂志风（theme09）

作者：chuspeeism；三方参考；等级3，仅确认方向。

深蓝底、衬线标题与橙色重点，组合刊头、人物、图文及深度专题。

## 可辨识规则
- 深蓝底与暖橙重点
- 衬线标题、无衬线正文的编辑配对
- 刊头、卷宗、专题和图文页兼容数据图表

## 场景
品牌故事 / 人物访谈 / 企业形象册 / 深度专题。

## 现有库关系
关联ID：editorial-magazine。

与现有编辑杂志高度相关；作为其 PPT 三方参考子主题，不新算通用语言。

## 成熟资料
固定版本 metadata.js 实际登记 111 个页面；对应 theme-runtime 模块、主题配置与官方预览资源均存在。
