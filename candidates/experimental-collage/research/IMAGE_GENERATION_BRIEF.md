# 原创图像生成简报

状态：**尚未生成。image2.5 是否可用，由主任务核实。**不得在产物中把未核实模型名写成已使用。建议分开生成两张源素材、再在实现中非破坏式裁切组合；不要直接要求模型生成“完整拼贴海报”，否则难以保持素材身份并做过程页。

## 共同约束

用途：虚构岸线观察主题的编辑式摄影拼贴。所有素材明确标为生成概念图，不冒充具体地点、纪实或科研证据。
要求：原创自然场景，无人物、文字、商标、水印、地标、报纸扫描、邮票。不得提供或附上 Stezaker 原作品作为图像参考，不使用“某艺术家风格”指令；不得复刻肖像上覆盖风景明信片、桥洞代替眼睛等标志构图。

照片A和B都要有可独立阅读的摄影空间：光线、景深、颗粒、材料细节。避免矢量化、三维塑料、均匀噪点、泛黄滤镜。风格不是怀旧，而是不同尺度的接触。

## A：远景岩岸 / 底层材料

目标尺寸：横向，建议2400×1600以上（按实际工具支持选最近比例，不承诺工具未支持的尺寸）。
原创提示：
“原创编辑摄影素材，一段无法识别具体地点的岩石海岸，从略高处斜向观看，海水与浅色岩面在画面中形成一条有节奏的斜向交界，从左下通向右上。水面有自然反光、岩面有细小裂纹，阴天柔光，可信的摄影景深，丰富中间灰调，黑白摄影，构图留有充足周边环境，非航拍地图。画面只有海岸与海水，无人，无建筑，无文字，无边框，无纸张道具，无绘画笔触。输出一张完整、独立的摄影图像，不要拼贴，不要生成排版。”
选片标准：轮廓有可接续的一段，但不能过分笔直成为抽象几何；左右均有足够信息，裁片盖住中心后仍保留空间感。

## B：近景潮痕 / 上层材料

目标尺寸：横向或接近4:3，建议1800px以上长边。
原创提示：
“原创微距编辑摄影素材，潮湿的深灰岩石表面，一道斜向潮痕与薄水膜穿过画面，细碎沙粒与小裂缝清楚可见，尺度接近手掌但画面不出现手或尺子。低饱和泥绿、冷灰和少量自然海水青，柔和侧光，纹理真实而不规则，浅但不夸张的景深。潮痕从左下向右上延伸，前后仍保留细节。不出现海天线、人物、文字、商标、纸张、胶带、边框。输出独立原始摄影，不要做成海报或拼贴。”
选片标准：斜向边界可与A试接，但材质颗粒和尺度明显不同；避免B恰好像A的放大截图，否则没有真正的异质关系。

## 组合与衍生，不新增无关图片

1. 保留A、B全幅母版及真实生成来源、工具/模型报告、生成时间、提示、尺寸、文件哈希。
2. 通过矩形裁片做至少3个接缝位置小样，挑选一个形态接续且透视/尺度有张力的位置。不得为匹配而把B变形拉伸；可有限整体等比缩放，但记录它是数字适配，与研究对象的实体原尺度工作不同。
3. 第1页使用组合；第2页用A/B母版缩略图和组合局部；第3页用组合边缘的窄裁片；第4页用相同A/B文件和同一裁剪参数。这样跨页能追踪同一材料。
4. 不把完整标题、数据表、图注生成进图像；这些必须保持可编辑文本。
5. 不需要仿旧纸底。若需纸边，只使用生成图本身自然边界，或制作极薄原创纸边；不可加入历史邮戳制造假档案身份。

## 许可与交付清单

- 参考研究图片：版权保留，无复用许可，不随交付发布，不输入图生图。
- 生成素材：记录实际生成工具条款与来源；不把“AI生成”误写成CC0，也不保证所有司法辖区的版权地位。
- 后续混入图库/照片：逐个记录作者、源URL、许可证版本、改作与商业使用条件、署名方式及下载日期；未核实不得用。
- 资产台账建议字段：asset_id / source_kind / generator_or_author / model_as_reported / prompt_or_source_url / generated_at / dimensions / edits / license_status / allowed_distribution / sha256。
- 交付必须含母版A/B、可追踪裁剪参数、成品图及静态缩略预览。只给一张合成图不能满足过程页。

## 视觉拒绝条件

- 出现拼贴通用图标：眼睛、嘴唇、手、红圆、剪报、胶带、钟表，但与岸线无关。
- 所有层只剩平面色块，移除照片后画面关系不变。
- 两图被无缝融合，接缝看不出，像一张真实风景照片。
- 为了“实验”而失去主锚点、显示随机碎片。
- 四页各生成不同风格的海岸，素材身份无法对应。
- 没有实际检查图片就声称“高质量/风格通过”。
