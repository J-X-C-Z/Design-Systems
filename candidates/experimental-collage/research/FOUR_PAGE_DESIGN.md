# 四页同内容样例设计稿

这是供后续制作的高保真布局与内容规格，不是已经渲染的成品。基准画布1440×900；网页可纵向延展；演示投影应另排字号。四页共享相同题材与事实，但承担不同阅读任务，绝不重复成三卡。

## 固定内容合同

主题：重新看见岸线。
说明：虚构研究计划，不是实测数据；照片为原创生成概念材料，不是现场纪实。
现有数值：12个观察点、3轮记录、30分钟。
歧义处理：旧资料未解释30分钟按单点、单轮还是整次活动计。本稿不擅自解释，统一写“时间设定：30分钟；分配方式待定”。实施者不得计算总人时、覆盖率或平均用时。
新加结构性假设：数据页允许把12点位×3轮画成36个计划空格；这是为展示记录结构作出的演示假设，不意味着已有36份记录或原计划要求每轮完整覆盖12点。若不愿增加假设，改成12行空白台账与旁注“3轮，分配待定”。本稿优先采用后一保守方案。

固定正文（原创，四页可按任务摘取）：
“岸线并不只是一条轮廓。远看时，它是陆地与水的分界；靠近时，它又分成潮痕、碎石与水面的反光。一次记录总要选择视点，也会留下没有被记录的部分。
我们把两张不同尺度的概念照片接在一起，检查一条边如何在另一张图里继续。接缝保留，不把两种空间修成同一个真实地点。
这是一份虚构观察计划：12个观察点，3轮记录，时间设定为30分钟。点位分配与时间分配仍待确定。图像用于提出问题，计划表用于保存信息；两者都不提供现场实测结论。”

## 第1页：引入 / 让边界变得陌生

**阅读任务：**先被一个图像关系留住，再看到研究主题。
**结构：**右侧大图、左侧短标题，下部留白与细小方法说明。不使用三项大数字英雄区。

1440画布布局：
- 页边72px。左栏 x72–420；右侧拼贴舞台 x470–1368、y88–690。
- 标题置左侧 y175，“重新看见 / 岸线”，两行72px黑体；标题不叠图，不歪斜。
- 标题下80px再放一个短句：“把远处的轮廓，接到近处的潮痕。”字号22px，两到三行。
- 右侧A为略高视点的黑白岩岸照片，B为斜向裂缝与薄水膜的微距，B矩形裁片约占A面积28–35%。B不是屏幕卡片，不加描边框、胶带或圆角。
- 接触处试三种候选位置，以两条斜线视觉延续、尺度差异仍明显的一个为最终方案。不是预先钉死坐标要求素材迁就。
- 图像下只写一行图注。页底左齐一行“12个观察点，3轮记录。30分钟的时间分配待定。”接着“虚构计划”标识。

**视觉关键：**主图不能被装饰文本抢走。允许约20%留白；不做满版纸屑。图像必须是摄影材料，不能用CSS岸线轮廓替代。
**手机：**标题、短句、主图、题注、计划说明依次排；图像整体缩放，不重排两个裁片使接缝断掉。
**动效：**默认无。首次出现的照片不必须淡入；用户滚动不是素材的理由。

## 第2页：阅读 / 观察从哪里开始

**阅读任务：**连续读完说明，同时查到构图的原始材料。
**结构：**文本主栏 + 窄旁注 + 跨页局部图。不是重复封面或大图左文右的翻版。

- 标题 x192、y92，40px：“观察从哪里开始”。
- 主栏 x192–820，y190起，正文20px/35px，完整放入固定正文的三段；段距22px。
- 旁注 x930–1230、y210，先放两个小尺寸独立素材样张A/B，上下排列、不同长宽比但同宽。下方写：“远景：轮廓。近景：表面。两张均为生成概念图。”
- 正文结束后放一幅横向接缝放大图，跨 x192–1230，固定裁片边界可见。题注：“这里对齐的是线的走向，尺度没有被统一。”
- 仅图片有材料感，正文底面干净。旁注没有阴影卡框，也不额外加入无来源引语。

**视觉关键：**读者能忽略旁注连续读正文；图像则让“接缝”被具体看见。大字不得压在正文上。
**手机：**正文优先，旁注接在相关段后；A/B按顺序显示，避免正文每两行被图打断。
**动效：**无；点击素材可查看原始图，属于查看功能而不是风格表演。若未实现放大，不画假放大按钮。

## 第3页：数据 / 一份还未填入结果的计划

**阅读任务：**分清计划、待定和结果，检查数字有没有被拼贴视觉歪曲。
**结构：**全宽台账 + 右侧解释条；避免三数字大卡和无实测数据的伪图表。

- 标题 x72、y70：“记录结构”；下方说明：“12个点位已编号，3轮与30分钟的分配仍待定。”
- x72–1060、y190–710：12行点位台账。每行有“点位01…12”“所属轮次：待定”“时间安排：待定”“结果：未记录”四列，行距约42px。每四行以轻微空白分组，不用错落纸条破坏列对齐。
- 表头明确写“演示计划表”。不使用进度环、百分比、热力色深或面积大小。
- x1130–1368、y195起的解释区只有两个稳定短段：
  “3轮记录：还未分配到具体点位。”
  “30分钟：还未确定按点、按轮或整次活动分配。”
- 右下可放一张很窄的接缝照片局部（最大约180×220），它只是本套语言的连续线索，不能覆盖表格，也不编码数字。
- 页底：“暂无实测结果。照片不作为数据证据。”

**视觉关键：**拼贴不必侵犯每一种内容。此页主要保持朴素台账，把其身份交给窄幅图像、字级、留白与同组摄影。实测信息的准确性优先于造型。
**手机：**台账换成12条紧凑文本行，每行显示点位、轮次待定、时间待定、未记录。允许展示式四页另出竖版，不能把横表缩到看不清。
**动效：**无数据不画生长曲线。不把空白格逐个点亮冒充进展。

## 第4页：过程 / 两张图如何开始对话

**阅读任务：**认出同一素材经过哪些编辑决定，并能够返回比较。
**结构：**大工作台 + 底部横向过程导航 + 侧面一段状态说明。不是三个等宽过程卡。

- 工作台 x72–1050、y145–695，浅中性底，显示可操作的两个素材对象。
- 右侧 x1120–1368、y190有状态题与说明，文字位置固定。
- 下方 x72–1050、y745为一条带三个状态名称的导航：“看原片 / 试接缝 / 看组合”。这三个词是步骤控件，不是卡片标题。
- 状态1：A与B分开，A稍大，均不旋转；说明“先保留各自的光线、视点和边界。”
- 状态2：A固定，B以有限平移进入；显示一次直切边界，不画发光扫描线；说明“比较线的走向，选择连接处；不把不同尺度修成同一现场。”
- 状态3：取消辅助边界线，留图像本身的接缝；说明“停在这个关系上，看看哪一处首先吸引你。”底部显示概念图身份。
- 提供上一步/下一步/重置，按钮靠工作台底而非漂在照片上。默认可停留的完整终态；无JS时显示成品和三句静态说明。

**视觉关键：**画面唯一运动对象是B及其裁剪视窗；标题、正文与控制区不动。允许手动切回“看原片”辨認两张图。
**动效：**450ms为待测起点，一次性、无弹簧；reduce-motion直接切换。连续点击取消旧动作，不排队。动画期间焦点保持按钮，状态文字通知不刷屏。
**手机：**舞台全宽，说明与按钮排在下方，控件至少44×44px；不用拖拽作为唯一操作。

## 制作后的逐页签核

- 引入：3秒看得出照片之间的关系；标题读得出；没有红圆/胶带救场。
- 阅读：正文一口气可读；旁注能补充视觉证据；图注不冒称实景。
- 数据：12行无遗漏；“待定”不能被装饰隐藏；没有新增数据结论。
- 过程：A/B身份前后一致；回退恢复原位；终态静止也完整。
- 四页并排：分别是主视觉、连续阅读、台账、工作台，不能只看见四次同一母版。
