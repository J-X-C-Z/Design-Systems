# 实验拼贴候选 0.1

状态：新候选，原“差”标签保持，未升等级。没有替换原样例、修改 SP 或推送 GitHub。

## 入口

- `index.html`：四页可编辑样例。
- `seam-comparison.html`：同一材料的三个接缝位置；①为工作默认值，须并排视觉判断。
- `responsive-check.html`：实际 iframe CSS 视口 1440/768/390/320px，用于桌面浏览器内检查响应式断点。不是物理设备模拟，不替代系统字体、200%浏览器缩放、辅助技术测试。

## 平面设计优先

引入页以一幅摄影关系为主；阅读页是连续正文与旁注；台账完整保留12行；过程页只说明同一张B如何进入固定A。没有3D、相机、空间导航、滚动劫持或持续自动播放。静态组合为初始终态。编辑工具折叠，非主视觉。

区别于旧版及中期几何：A/B保留具体照片的光照、视点、尺度与材质；不使用红圆、黄签、米黄仿旧、胶带或统一锯齿来证明拼贴。单一矩形裁片是摄影空间的截断，不是彩色构成模块。

## 原创生成素材

A：1536×1024黑白远景岩岸。B：1448×1086近景湿岩潮痕。均来自用户授权的普通ChatGPT网页新对话 Medium，底层图像型号未显示，不宣称已确认image2.5。已实际查看两张母版像素；没有重采样、无缝融合或改画。详细提示、时间、真实来源及哈希见 `assets/` 台账。

这低于最初建议的大像素母版，当前只用于屏幕候选。没有声称2400px、印刷就绪或不存在的生成细节。

## 非破坏式组合

A舞台比例1.49，接近母版1.5；B视窗宽52%、高57%，覆盖29.64%面积，object-fit:cover保持比例。候选①B位置25%/20%，②30%/30%，③38%/12%，裁切中心50%/50%。真实浏览器三方案截图已并排查看，③两端接近外部岸线，①/②更像纹理覆盖，因此选择③为新的工作默认。它仍只是候选，不因数字或一次观察就判质量通过。

四页共用同一母版与接缝参数。工作台中A占舞台宽74%，A始终固定；B的终态坐标按同一组合等比例映射。阅读局部和台账局部也保持内部1.49构图，仅外层裁窗，避免变更视窗长宽比后二次重裁图像。原片状态把B放在旁边，用户触发后仅B改变位置/尺寸；同一DOM对象与图像身份保留。

## 交互与可编辑性

- 四页切换与URL hash；无JS时四页顺序显示，图片使用本地母版。
- 文字编辑采用纯文本，粘贴不注入HTML。
- 本地PNG/JPEG/WebP素材替换，不传到网络；JSON导入进行类型、格式、大小、裁切数值校验。替换素材显示“用户提供、来源与许可待核”，不会自动称其为已核实生成素材。恢复默认重新载入初始母版与位置。
- JSON导出保存文字、素材和裁切；HTML导出保存独立可再编辑状态，并给无JS提供图像背景。
- 可逆状态切换、上一步/下一步、暂停/继续、重播、恢复终态。
- 450ms是本项目待测候选值，非艺术史证据。原生Web Animations，无GSAP/Reveal依赖。
- 减少动效在切换前读系统偏好，也提供显式开关。快点取消旧动作，不排队；离开过程页取消动作；终态静止。
