# 世纪中期现代：可编辑平面候选

日期：2026-10-11。研究范围为 Girard 约1960–1961年活泼印刷识别的当代原创适配。历史作品仅作研究链接，不随包复制。四份研究文档保留形成时的研究状态；实际实现与验证以本文及 QA-RESULTS.md 为准。

## 使用

打开 index.html。顶部切换招贴、阅读、台账、标本索引；可同时展示四页及切换黑白查看。编辑工具支持文字、三种主题色、所选图形内线微调，导出 JSON、独立 SVG 和保留编辑功能的单文件 HTML。文字替换按纯文本处理；自定义配色需要重新检查对比度。HTML 无外部字体、图片或运行时依赖。

本轮所有图形为原创 SVG，两条路径分别构成不规则闭合边界及内部岸线。A 为横长视窗，B 较高且内线缓弯，C 保留 A 外轮廓并在内线右端形成较深缺口。没有生成照片、仿旧纹理或历史图像。系统宋体回退并未打包分发；在其他系统可能不同。

## 构图

1. 中轴招贴：标题、原创标记、窄色带与计划事实形成清楚顺序。
2. 偏轴长文：稳定正文、窄边栏和短旁注，色带承担停顿。
3. 台账：完整12行，保留实际所需长度，不把信息缩成装饰。
4. 标本索引：大小不同的三个开放标本及固定／变化说明。标本大小不表示数据。

默认静态，无播放或循环动画，暂停不适用。减少动效不影响信息与功能。

## 事实及分类边界

示例为虚构观察计划：12个观察点、3轮记录、30分钟的具体分配范围待定；没有真实观察结果或效率数据。旧样例的“差”及二级适配状态保留。新候选不代表用户已认可，不新增语言数量，也不自动升为一级。

## 导出

UTF-8 BOM 与文档前部 charset 明确中文编码；仅序列化页面 head/body，排除托管环境附加界面；JSON 模型中的小于号安全转义，重开后恢复原文字。交付 index.html 来自真实浏览器最终默认状态导出，原始字节保留。
