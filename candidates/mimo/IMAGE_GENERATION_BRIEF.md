# MiMo 平面应用：图像决策与素材边界

状态：本轮不生成图像，不制作页面。与其余三份文件组成研究包；不是新 MiMo 版本。原“差”、Level 2 不变。

## 决策：本候选没有生成式图像需求

四页任务是把计划的数量、范围与未知说清。需要的载体是可编辑中文、索引、细线与纯色面。摄影会虚构点位，水墨岸线可能误导地理关系，抽象曲线可能被看成数据，AI整页图会破坏文字与对象编辑。因此不因官网图中有笔触，就增加生成图。

这不是 MiMo 全局“禁止图片”的规则。canonical v2.0 明确允许与内容有关的摄影、插画和科学图形；未来真实项目有足够内容和使用权时仍可使用。此处只决定当前四页不需要。

## 已有资产如何处理

- 官方 Code feature-model.png：已目视的研究资料，只链接，不嵌入候选，不打包，不作为生成工具参考输入，不描摹笔触、人物、终端字标。
- v2.0 用户原创 SVG：Quiet Contour、Evidence Flow、Focus Frame、Index Rule 均可共享复用，但“可用”不等于“必须用”。本候选不采用带数据联想的曲线或复杂轮廓。
- Index Rule 若确有阅读方向用途，可作为独立可编辑线/箭头使用，保留用户原创来源；不用时可直接省略，不发明替代品牌徽记。
- 纯色背景、分隔线、强调面由独立矢量/HTML对象完成，无需位图纹理。

## 若后续内容变化

先明确新图表达哪个事实、是否会被误认真实地点/实测/记录结果，再决定摄影、手工矢量或生成图。涉及官方标志、字体、人物照片与地点实拍应核对使用权和真实性。不得用 AI 图冒充 Xiaomi 官方资产或用户原始作品。

如果用户另行选择图像方向，应先提交一张无文字素材样张与用途解释，获得方向确认后再应用。标题、数字、图注仍是独立文字；不生成带完整版面和文字的海报作为“可编辑HTML”。当前没有这种扩展请求，也未发起生成。

## 后续验收清单

关闭装饰后四页的事实与读序仍完整；图形不暗示地图/波形/路线/进度；主题切换只改变绑定样式；导出重开保留独立对象；研究图不混入交付资产。未实施的检查不得记成已通过。
