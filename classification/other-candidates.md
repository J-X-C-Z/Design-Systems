# 其他候选、分支与技术记录

这24条保留 Batch02 的原始处置：B分支3、C补充7、D技术7、E待验证7。它们不新增独立语言计数；E类尚未确认，不被强行赋予“仅确认方向”的等级。关联的外部资料可在三方参考索引中以三级收集。

| 名称 | 原类别与判定 | 下一步 |
|---|---|---|
| IBM Carbon | B：企业组件完整，但本轮未证明超出现有视觉逻辑的独立身份 | 保存企业工作台分支及运动分级方法；不新增语言 |
| Atlassian Design System | C：本轮证据主要支持规范方法，不足以把品牌当独立风格 | 旧档案补充：语义 Token 与体系组织方法 |
| Shopify Polaris | B：业务语义与组件专化成立，独立视觉增量尚不足 | 保存商家工作台分支；当前与历史实现区分 |
| Duolingo Shape Language | B：形状与嘴型细分有用，但仍属角色型反馈语法 | 增补角色一致性与可说话角色分支，不重复计数 |
| Spotify Encore | C：官方工程资料支持协作/可访问方法，非新视觉语言证据 | 保存跨平台可访问性方法；不混淆营销品牌 |
| MIT Media Lab 身份体系 | C：新组织案例增加身份生成方式，但仍落在既有网格逻辑 | 旧档案补充：网格驱动多单位身份 |
| NASA Graphics Standards 再版 | C：航天题材和再版不证明新语言 | 保存规范表达与历史手册入口；不是完整已读档案 |
| MIT Technology Review 改版 | C：科技主题不改变编辑语法；新案例不新建语言 | 旧档案补充：科学技术出版的编辑身份 |
| DIA × Pinterest | C：新的收藏/组合语义是案例增量，不充分构成整套新语言 | 旧档案补充：从产品动作提炼品牌运动 |
| Blade Runner 2049 光学界面 | C：光学档案逻辑有差异，但单片内多个系统不能直接合并为通用 FUI | 保存原团队的光学/叙事状态证据；独立归纳尚待更多案例 |
| visionOS 空间界面 | E：可能有任务空间/输入方式的真实增量，不能仅因三维而去重；当前证据不足 | 下一步需完整 HIG、真实交互与旧档案指纹 |
| Fluent 2 | E：不能仅看品牌/表面认定独立，也不能未读全便归旧；维持待验 | 需获取完整六维规则与实操，再判与既有差异 |
| Memphis | E：反功能/反秩序潜力可能独立；不能因为几何相似便归为分支，但完整证据尚不足 | 扩展原始宣言、多媒介作品及可执行边界 |
| De Stijl | E：可能新增开放空间构造；本轮未完成跨媒介提炼，不能简单当现代主义同义词 | 追原作与空间/家具/排版关系，非直接认定分支 |
| Wabi-sabi / 侘寂 | E：哲学/审美标签过宽；不能只凭米色、颗粒和不规则就构成一档 | 需具体项目与整体规则；不把全部茶器等同侘寂 |
| 玻璃/背景模糊 | D：只改变表面，不能独立定义阅读、布局、操作 | 共享技术索引：backdrop-filter；可用性需另验 |
| Neumorphism 双向阴影 | D：阴影不提供完整任务和空间语法；不独立收录 | 保存阴影实验入口与可访问性风险 |
| Bento 卡块布局 | D：只是布局选择；本轮不把流行称呼升级为语言 | 共享布局参考；CSS Grid 为实现资料非风格定义 |
| Mesh-like 渐变 | D：渐变本身没有组件或阅读语法；CSS 多径向层仅为近似 | 共享表面实验；不冒称真正网格渐变实现 |
| 可变字体 | D：技术可支持多种相反语言，不能单独计数 | 共享字体能力与逐字体授权记录 |
| View Transition API | D：API 不决定镜头/节奏/语义，不能当一种语言 | 共享实现入口，具体运动属于各 Language |
| Risograph / 套印 | D：工艺可以服务多个风格；不是完整语言 | 共享工艺知识；成品插图仍需授权 |
| Constructivism | E：思想和构图可能具有独立增量；不能作为历史后继的同义名删除，但本轮证据未成体系 | 继续原作与方法研究；当前不计 A |
| Porto / White Studio 城市身份 | E：地方图符语义可能提供增量，但一段视频入口不足以证明完整系统 | 优先补组合语法、实际应用、运动及许可 |
