# 生成艺术 / Generative Art 1.0
将作品身份放在可说明、可复现的规则中，让每幅图像成为系统的一次实现。
主类型：动态与生成视觉；辅类型：展览和品牌视觉。不是给普通页面加随机粒子，也不是统计图表。

打开 `specimen.html`：参数工作台、三幅同规则系列、展览票面迁移、正反例。无联网/安装；修改种子、线条数与偏移后可导出 SVG。`engine.js` 是独立、无依赖的原始生成器，Node 和浏览器都能使用。
`sample-*.svg` 是固定参数的可编辑输出；`tokens.json` 保存语义参数、范围和复现条件；`LANGUAGE.md`、`EVIDENCE.md`、`MOTION.md` 等解释语言；`VALIDATION.md` 区分生成器实测、静态图形检查与尚未完成的浏览器验收。

原创算法不是对某位艺术家作品的复刻；图形不代表海岸/气候/声音实测数据。版本和参数应随导出文件保存。
