# 一次路径显露
触发“播放生成过程”；对象仅当前 SVG 的 path；几何在播放前一次性计算，pathLength=1，stroke-dasharray=1，stroke-dashoffset 从1到0，3秒线性，只播放一次。它表现路径的展示，不声称重现算法逐步积分（此算法是直接采样）。
停止、重新生成、页面隐藏和系统减少动效改变都会移除播放类，显示完整终态。重播清理唯一计时器；不叠加动画、不改种子。导出 SVG 不含播放 CSS，所以播放前后内容相同。
减少动效时直接显示完整图并说明静态模式；默认无自动运动。无JS显示预生成 sample-42.svg；三个固定系列始终可见。
预算：最大72条×81点；一次生成不超过5832个点，字符串拼接后单次DOM替换；播放不重新生成点，无rAF循环。真实浏览器帧率与低功耗设备尚未测试；若用于投影长期运行，另定义时间步、暂停与资源上限。
