# 媒介适配
网页工作台：参数输入有 label 和数值范围；生成按钮在确认输入后更新一次画布，避免每次拖动进行大规模DOM更新。画布有文字说明，不能要求看图才能知道参数。
展览/品牌：保留小号版本与配方；图像可裁切，但同系列裁切策略一致。主体文字不放在最密线区。
PPT/SP：推荐导出的静态SVG；外部编辑器可继续改路径，但改后不再宣称由原参数精确复现。保留修改记录。
印刷/绘图仪：SVG线宽需要按输出尺寸重新测试；交叉线和多色线不能直接当作绘图仪路径规划。未交付印刷色彩配置或绘图仪G-code。
可达性：艺术作品描述生成规则而非逐点朗读；正文、控件和错误信息使用高对比。复杂图形只作为作品，不能作为唯一导航。
