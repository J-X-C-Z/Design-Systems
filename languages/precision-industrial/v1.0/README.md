# 精密工业 / Precision Industrial 1.0
把设备的因果关系变成可读界面：读数、单位、阈值、控制和确认始终对应。

主类型为产品与交互，辅以技术出版。适用于测量工具、研发报告、设备介绍、实验记录；不适用于未经工程验证的真实安全控制台。

- `LANGUAGE.md`：核心、分支、边界及生成语法。
- `EVIDENCE.md`：2026-10-11 来源与证据分级。
- `tokens.json` / `language.css`：原创建议参数与语义映射。
- `specimen.html`：离线打开。校准台 → 规格/记录 → 新内容迁移 → 正反例。
- `MOTION.md`：插销式位移、读数响应与可中断状态。
- `AI_CONTEXT.md` / `ADAPTATIONS.md`：创作协议与产品边界。
- `VALIDATION.md` / `validation.json`：实际运行记录和限制。

不需要安装或联网。样例可直接编辑 HTML、CSS、JSON；所有数值是虚构教学数据，不连接任何机器。未包含品牌资产或第三方字体。
