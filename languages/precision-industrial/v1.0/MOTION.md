# 运动：定位、接合、确认
本包的动作是原创数字适配，不是假称复刻真实仪器物理特性。

1. 设置偏移：原生 range 输入；指针随数值变化，160ms ease-out 接近目标。数字立即更新，不进行滚轮式跳数。重复输入以最后值为准。
2. 开始模拟校准：锁定编辑，依次显示“读取基准→比较偏移→写入模拟记录”，每段 500ms，轨道长度表示教学阶段而非实际设备进度。禁止虚构真实加载完成率。
3. 取消：清理唯一计时器，恢复可编辑状态；记录写“已取消，未保存结果”，不显示成功灯。可立即重试。
4. 成功：只在三步结束后写入结果；模块边缘一次 320ms 的接合位移（4px→0），不使用弹簧过冲、抖动或闪烁。
5. 减少动效：CSS 禁止过渡/动画；操作流程保留状态与文字，阶段定时仍表达教学顺序，不自动滚屏。系统偏好改变即时生效。
6. 页面隐藏时取消正在运行的演示，防止后台计时完成后造成突兀状态。离线/无 JS：读数与规格仍可读，noscript 明示交互不可用。

性能预算：仅 transform/opacity/轨道宽度；没有持续 rAF、Canvas、外部字体、视频或网络。轨道宽度局限于局部元素。真实设备需另测输入延迟、屏幕刷新和恶劣环境。
