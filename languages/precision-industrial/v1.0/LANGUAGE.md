# 精密工业：让秩序可操作
## 对象与增量
这是测量、操作、确认之间的语言，不是“机械纹理”的装饰。与瑞士信息设计共用对齐和明确层级；区别在于信息的邻近由物理/任务关系而非纯排版关系决定。与 Batch02 的 TUI 不同，它不模拟命令行，也不要求字符单元。与低技术基础设施不同，它不以暴露实现结构为审美目的。

## 四层体系
1. 核心：对象身份、量值语义、状态证据、可预测控制。
2. 配置：浅色仪器 / 深色监测 / 纸质技术说明；改变照明和密度，不改变状态意义。
3. 资源：读数组、量程轨、分步校准、横向规格表、轴测对象示意。按任务取用。
4. 适配：网页、投影与印刷分别处理触控尺寸、字号和静态记录。禁止将样例的三栏当作唯一模板。

## 生成语法
先列对象与量纲 → 定义状态和动作 → 把同一闭环放在同一区域 → 给跨区域连接编号 → 用对齐核对数值。每屏最多一个“待确认”的主要操作。

### R1 量值永不脱离语义
目的：防止大数字被误读。依据：产品可理解性 [E1] 与工业任务导向 [E2]；数值分组细则为原创适配。
做法：参数名 → 数字 → 单位 → 合格区间 → 数据时间。数字采用等宽数字，单位小一级但不低于 14px。
允许：仪器首页省略次要来源，详情中补全；打印时保留采样说明。
正例：偏移 0.04 mm，允许 ±0.10 mm，模拟样本 03。反例：只写巨大的 0.04 和绿色灯。
验证：遮住颜色后仍能判断测量对象与范围。

### R2 颜色不能伪装成证据
目的：将视觉状态与实际状态分开。默认中性背景；异常出现时才引入状态色并同时写原因。绿色仅表达已经检查的通过，不等同“机器在线”。等待、未测量和错误分别写明。
允许：品牌强调色用于导航；不得占用故障语义。正例“校准完成（模拟）”；反例未运行却显示“系统安全”。
验证：逐一列出 UI 文案与状态机条件；刷新后不得残留未发生的成功状态。

### R3 控制拥有清晰机械关系
目的：在连续操作中维持可预测性。滑杆直接更新读数和位置；“运行”只启动所描述的模拟过程；取消立即停止。控制与输出距离小于相邻独立输出距离。
允许：键盘输入替代旋钮，不强制圆形控件。反例：以装饰旋钮替代原生可达输入、点击后播放与读数无关的动画。
验证：键盘完成改值、开始、取消、重试；重复触发不叠加计时器。

### R4 几何来自装配而非炫技
面板边界表达功能模块；分缝是区分任务的线，不用螺丝、拉丝纹理覆盖正文。比例以 2:1 主次区和同轴排列为起点，可根据任务更改。
正例：主读数与校准轨共享中心轴；反例：每张卡片都添加金属高光。
验证：移除材质仍能辨认量值和动作。标尺刻度必须对应真实范围；纯装饰刻度应去除。

### R5 信息密度遵循操作频率
经常查看的读数最大；偶尔需要的型号、修订、来源缩小；长说明可折叠，但错误与取消不能隐藏。每模块留一个明确视觉入口。密度提升优先减少外距，再缩短表述，最后才考虑字号。
允许：规格手册高密度；新手校准向导低密度。反例：把所有说明做成 9px 等宽字体。
验证：中文 120 字说明、最长单位与 6 位数同时出现仍不溢出。

## 三个真正不同的分支
- 仪器工作台：浅壳体、暗读数窗、单轴控制，强调人手与参数的闭环。用于交互样例。
- 技术出版：白纸、细规则线、分解示意、编号注释，强调可追溯与印刷。用于规格页。
- 现场监测：暗底、中性图表、稀疏警报色、时间戳，强调一眼区分当前/历史状态。使用时需另做现场照明与安全审查。
三者共享量纲、状态文案和对应关系。若大量无功能装饰、数字不带单位或颜色占据全部层级，便破坏身份。

## 内容与中英文
用动词+对象命名动作，例如“开始校准”“取消校准”；不给模拟功能起“启动机器”的名字。英文只作为型号/短标签，不重复每一段中文。中文用系统黑体，数字用系统等宽；避免用西文字体缺字回退制造不均匀间距。
长中文按语义段落正常折行。数值与单位成组，但整组可在窄屏换行；不固定整页高度。

## 新内容迁移
同一虚构“岸线水质观测”内容贯穿规格与记录：12 个采样点、3 次复测、08:40 的观测窗口。未参与第一轮提炼的“图书馆空气质量”改用 CO₂ ppm 和相对湿度 %，保留读数/单位/阈值/记录关系，不保留旋钮和机器外观。由此检验语法是否独立于工业物件。
