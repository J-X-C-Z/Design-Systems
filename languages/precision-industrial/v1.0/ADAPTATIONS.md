# 产品适配
## 网页
操作界面保留原生 label/input/button，触控目标至少 44px 是本包舒适性默认值。小屏将对照并排改纵向，保持 DOM 顺序。状态用 aria-live=polite；错误不得只靠颜色。本文不声称完成 WCAG 全项审计。
## PPT / SP
技术说明一页只呈现一个因果链；量值名/单位不得因模板字号不同分离。大屏正文建议 24–32pt，投影前按实际观看距离检查。动画不能依赖鼠标 hover。静态导出保留最终状态与步骤编号。
## 印刷
白背景、边框、表头重复；交互部分打印默认状态与模拟声明。HTML 的浏览器打印样式只做基础整理，不保证所有打印机分页一致。
## 真实 HMI
这是设计研究与演示资源，不是可投入生产的安全 HMI。上线前必须由工程团队审查量程、权限、报警优先级、故障恢复、误操作和现场可达性；不能把这里的颜色或时间参数当成工业标准。
