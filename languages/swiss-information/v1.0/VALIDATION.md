- JavaScript 语法可解析。

- 页面存在原生静态回退、移动断点、减少动态媒体规则和用户/系统 OR 判定。

## 建议的浏览器补验步骤

1. 直接打开 specimen.html，无网络时确认研究内容可读，控制台无脚本错误。
2. 在 1440、768、390、320 px 各查看两分支四场景；再开启强调层级与紧凑密度，检查完整文字、表格和按钮。
3. 在目录搜索“网格”“TYPE”“01”和不存在的字符，清空后确认焦点回到搜索框。
4. 交替更改密度和排序，确认最后一次输入决定结果、稳定 ID 不变、动画不残留。
5. 切换时长/容量，检查数值、单位、刻度和表格同步。
6. 仅用键盘操作所有控件；确认焦点可见，隐藏场景没有额外焦点，详情可展开关闭。
7. 系统启用减少动态，再关闭页面内开关；系统偏好仍应优先。无 JavaScript 时静态回退应可读。
8. 最后检查打印与目标平台字体。发现问题先修正并重跑，再把状态更新为已通过。
