# 瑞士信息设计的屏幕动效语言

版本 1.0.0-candidate · 2026-10-10 · 全部时长与实现为本包原创候选。

## 目的

让读者跟得上状态、顺序和空间关系。动效不能代替清楚的静态排版，也不能成为用户等待信息的原因。本规范是屏幕媒介扩展，不是历史瑞士设计的统一惯例。

Codrops 的 Grid Layout Transitions 提供“网格可以动态重排”的现代技术参考：https://tympanus.net/Tutorials/GridLayoutTransitions/ 。本包未使用其源代码、图片、GSAP 或其他外部运行依赖。

## 三层预算

| 层级 | 候选 | 用途 | 不做什么 |
|---|---:|---|---|
| 即时结果 | 0 ms | 表单值、选中语义、文字提示、减少动态 | 不等动画结束才更新数据 |
| 微反馈 | 120–160 ms | 按钮颜色、场景区域短淡入 | 不移动按钮命中位置 |
| 关系重排 | 320 ms | 目录密度变化、排序、同一对象的新位置 | 不把消失对象飞出屏幕 |

默认缓动：cubic-bezier(0.2, 0, 0, 1)。此曲线是本包候选，不来自历史资料测量。

## 状态转移契约

### 目录排序与密度变化

1. 记录当前可见项目边界和稳定 ID。
2. 取消旧动画，计算最新排序或布局；同步更新 DOM 顺序。
3. 立即更新标签、结果数量与 aria-pressed/selected 状态。
4. 在新布局上以 FLIP 位移从旧位置过渡到新位置。
5. 动画完成后清除瞬态变换；新输入可以直接中断。

排序中的同值项以 ID 升序作为稳定次序。快速重复点击不会生成动画队列；最终状态始终以最后一次输入为准。筛选没有旧对应项时直接显示结果，不制造虚假“飞入”路径。

### 场景切换

内容区域切换为研究、目录、数据或海报。控件保持原地，当前状态在按钮语义中可读取。主要内容可作 160 ms 轻微透明度反馈；不自动滚动，不抢走焦点，不让不可见场景保留可聚焦控件。

### 分支切换

由信息秩序切为文化海报时，改变标题尺度、强调面的面积和构图比重。静态信息立即更新。此切换无需复杂 morph；不让每一个字单独延迟入场。

### 数据指标切换

数值、单位、最大刻度和明细表同时更新。不使用从零滚到目标的数字计数器，以免被误认为正在采集实时数据。图表保留文字值；过渡失败时仍能比较。

### 详情展开

使用原生 details/summary，默认没有高度动画。展开内容在正常文档流里，关闭后焦点仍在 summary 上。减少对自制弹层、焦点陷阱和复杂退场逻辑的依赖。

## 减少动态优先级

有效减少动态 = 系统 prefers-reduced-motion 为 reduce，或用户勾选“减少动态”。二者任意为真即停用非必要动画。取消勾选不能覆盖系统设置。

系统偏好在页面打开后变化也要响应。开启减少动态时取消正在播放的 WAAPI 动画，并保持最终正确布局。减少动态不意味着去掉选择、排序、筛选等功能；只移除过渡。

参考 W3C 交互动效说明：https://www.w3.org/WAI/WCAG22/Understanding/animation-from-interactions.html 。本包没有据此宣称整体 AAA 合规。

## 禁止默认启用的运动

- 无用户请求的无限滚动字幕、旋转几何体和浮动装饰
- 页面加载时先隐藏全部内容再逐项揭示
- 鼠标追随、弹性过冲、触发器远离对象的运动
- 每次滚动都让读者重新等待相同段落
- 仅为表现技术而遮挡内容的全屏转场

若真实任务需要连续过程可视化，应另写暂停、恢复、进度和失败契约。当前样板不包含连续动效。

## 动作与测试映射

| 控件 | 可见效果 | 可访问性反馈 | 验收 |
|---|---|---|---|
| 四场景切换 | 内容结构改变 | 按钮按下状态、场景标题 | 所有场景均可键盘进入 |
| 两分支切换 | 同内容不同表达强度 | 当前分支文字 | 内容事实不变 |
| 紧凑目录 | 列数与间距改变 | 按钮当前状态 | 文字和目标不缩到不可用 |
| 排序 | 项目重新排列 | 当前排序、结果数量 | 稳定 ID，最后操作生效 |
| 文本层级 | 展示标题尺度改变 | 选中状态 | 正文仍清楚、无裁切 |
| 显示网格 | 检查层出现 | 开关 label | 不挡点击、不读作内容 |
| 减少动态 | 非必要动画立即停用 | 控件与系统提示 | 功能保持，动画数为零 |

## 适配注意

WAAPI 不可用时，直接使用最终布局。未启用 JavaScript 时显示研究摘要与静态节目数据，并说明增强交互未启用。整个 HTML 可以离线打开，不依赖 CDN 和网络字体。样板只存内存状态，不写浏览记录、不联网跟踪、不保存个人数据。

## 什么证据足以说通过

静态检查只能证明规则存在，不能证明视觉无误。最终验收必须结合浏览器行为、截图目视、响应式边界、键盘与减少动态。具体执行过的检查和未覆盖范围记录在 VALIDATION.md；设计意图不计为测试结果。
