# 瑞士信息设计独立资源包

2026-10-10 · 1.0.0-candidate

从 DESIGN_LANGUAGE.md 阅读完整研究；用浏览器打开 specimen.html 体验两分支、四场景及已实现的交互。当前环境未完成真实浏览器验收，详见 VALIDATION.md。样板是离线单文件，不需要安装、构建、联网或字体 CDN。

## 文件导航

- DESIGN_LANGUAGE.md：深度研究、来源观察、DNA、两分支、中文与响应式、组件、反例和适配方法
- design-tokens.candidate.json：本包原创候选值，非历史官方参数，非既有产品主题
- reference-inventory.json：每条来源的定位、证据等级、读取与视觉核验范围、可借鉴内容及权利边界
- motion-language.md：状态与重排、减少动态、中断和测试契约
- specimen.html：原创可操作验证样板，含信息秩序/文化海报，研究/目录/数据/海报四场景
- specimen-data.json：样板四条原创演示数据，便于替换和校对
- VALIDATION.md：真实执行的验收、已修正问题、测试限制
- qa-results.json：本次静态、纯函数与结构检查结果，明确浏览器未执行
- design-preview.svg / design-preview.png：原创静态设计样张，不是 HTML 浏览器截图
- verify.cjs：可选 Node.js 纯函数复验脚本，无第三方依赖
- SHA256SUMS.txt：文件完整性核对

## 建议查看顺序

1. 在研究场景理解内容与层级，再切信息秩序/文化海报，观察同一内容的不同强调。
2. 打开目录场景，测试搜索、无结果、排序、详情展开、紧凑密度。
3. 打开数据场景，切换时长/容量，核对图表、单位与明细表。
4. 查看海报，确认主标题、日期、地点及节目单在窄屏仍完整。
5. 打开“显示网格”“强调层级”和“减少动态”，检查结构与可用性。

重置按钮恢复初始场景、分支、密度与排序，但仍尊重系统减少动态设置。样板中的活动、日期、地点、容量、时长与研究内容均为原创演示，不是真实活动、调研成果或用户日程。

## 复用边界

本包的文字规范、候选值和样板为原创研究输出。参考资料的商标、字体、海报、书页和代码未包含在分发包中；链接不是再分发许可。不要将来源作者的作品、字体名称或品牌移植成自己的身份。

候选 JSON 是本包独立格式，不承诺 DTCG 或某个产品的直接导入兼容。把语义角色通过项目适配层转换即可，不要把研究资源直接混入 MiMo 或 SP。更换字体与内容后重新检查字形覆盖、行宽、对比、键盘和目标设备。

HTML 默认使用本机 Arial/Helvetica 系列与系统中文 fallback。不同操作系统可能出现不同换行。文件打开即可运行；来源链接只有主动点击才访问外网。没有自动网络请求、第三方脚本、CDN 字体或跟踪。

## 版本与存放

归档目录：本目录；与 MiMo 研究资源分开维护。

本轮只完成这一种语言的独立精修，不包含其他风格。后续真实项目应以具体任务反馈迭代；本包没有修改任何既有项目代码。
