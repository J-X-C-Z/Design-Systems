# 枝条舒展
本包演示生长是流程隐喻，不是生物学时间轴。
触发：用户选择“观察种子/观察叶片/写下记录”；对象：同一株植物的茎和叶；终态分别为低矮、展开、完整。茎沿底部原点 scaleY，600ms cubic-bezier(.2,.7,.2,1)；叶片使用同一原点缩放/旋转，延迟 120ms。只在显式“播放本步动作”时运行一次，不自动循环。
停止：按钮“停止动作”移除动画类，保留当前步骤终态；重复播放先清除旧计时器与类，下一帧重新开始，次数不堆叠。切步停止旧动作并更新 aria-pressed 和说明。页面隐藏取消动画。
减少动效：读取系统偏好；按钮点击直接显示终态和文字“已显示静态步骤”；CSS 兜底 animation:none。全流程不依赖动作显示隐藏信息。
无 JS：完整植物与三个说明都可读，noscript 说明交互不可用。SVG 使用 title/desc；纯装饰的叶片不单独进入辅助技术。
预算：不超过 1 个计时器，3 个动画组；无噪声滤镜、视频、外部请求、持续 rAF。真实低端设备和浏览器测试待补。
