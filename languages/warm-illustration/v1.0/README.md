通过可辨认的形状、有人情味的动作和有留白的场景，让信息更容易靠近。
主类型：插画与品牌视觉；辅类型：轻量引导交互。适合教育、社区活动、生活服务、入门引导。温暖不等于幼儿化，不用表情掩盖错误。
