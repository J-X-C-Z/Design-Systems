# AI 使用协议
先明确谁在做什么、情绪强度和信息目的，再选分支。读 LANGUAGE.md / EVIDENCE.md / MOTION.md，使用已有语义色与原始 assets.svg；不要复制参考品牌角色。
提示：为成人社区花园观察日生成邀请海报、三步指导、雨天改期提示。角色与植物可原创变化，但错误和改期不能被庆祝语气掩盖；所有说明保持可读。
迁移：把同样的友好语气用于邻里夜读，改用书本和灯，不沿用植物成套贴图；说明保留的轮廓/关系/留白规则。
参数扩展：可以调整画幅、主题、主体比例；必须保持线重、色角色和一种空间表达。不得凭肤色/服饰推断人格，不拿残障作视觉笑料。
输出自检：单色可辨；80px简化；图文不互相遮挡；状态真实；运动可停；静态可读；资产原创/许可清楚。未做的视觉与用户测试必须列出。
