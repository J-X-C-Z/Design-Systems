# 场景适配
海报：一幅主场景和一个行动信息组；具体时间、地点、报名方式不藏在叶片里。样例不是真实活动，不产生报名。
网页：原生按钮与 label，信息型 SVG 提供 title/desc；装饰图 aria-hidden。错误用清楚文字与可执行下一步，不能只换表情。暗色文字与浅底是默认，最终需测试实际对比。
演示：每页一个情境，不强制每页都有人物；插画可以从全景裁到物件，但不能切断重要动作接触点。静态导出保留完整动作终态。
印刷：先测试灰度，再决定是否加纹理；避免薄线在小尺寸丢失。本包无印厂色彩配置，不宣称 CMYK 打样通过。
人物扩展：要结合真实受众验证姿势和物件文化含义。没有实际参与者研究时，标记为设计假设。
