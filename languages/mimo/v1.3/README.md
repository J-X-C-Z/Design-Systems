# MiMo-inspired Design Language — Independent Research v1.3

本资源为**原创设计语言研究**，不代表 Xiaomi 官方 Design System，也不等于 Superior Point 主题包。

## 新增成果

- `kit/rth-design-language.css`：可独立复用的语义 Token 与轻量组件样式。
- `kit/design-language.profile.json`：两种视觉模式 × 三种场景的简洁设计上下文。
- `MiMo_Design_Grammar_Lab_v1.3.html`：单文件离线实验台；双模式对照、三场景、中文/长文压力测试、状态反馈。
- `MiMo_Design_Language_Research_v1.3.md`：实证/推论/未实测分层报告。
- `preview/`：本机 Chromium 截图与测试结果。

**来源边界**：官网字体、像素值和动画曲线因无法获取官网运行时 CSS、浏览器录屏而仍未完成实测。上述 CSS/Token 是原创候选，不是克隆官方样式。
