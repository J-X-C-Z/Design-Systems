01 / TYPOGRAPHY
Type as architecture

标题的比例与字距构成空间，而不是依赖过多装饰图形。

02 / INFORMATION
Indexed hierarchy

编号、日期、短标签与细分割帮助高密度信息被快速扫描。

03 / INTERFACE
Direct tools

让命令、输入、模型选择与状态本身成为界面表达。

04 / EMOTION
Rational, human

理性但不冰冷，保留适度温和的底色和文案语气。
