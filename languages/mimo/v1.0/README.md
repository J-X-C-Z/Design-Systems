# MiMo Design Language Study v1.0

**独立个人设计资源库的一份研究性提炼；非小米官方品牌资源，也非 Superior Point 主题包。**

## 文件

- `MiMo_Design_Language_Study_v1.0.md`：完整中文调研、证据、设计身份、四个表达模式、组件、动效、验证方案与待查项。
- `design-tokens.candidate.json`：可被个人项目使用的**候选语义变量**，不是 MiMo 官方 CSS。
- `reference-inventory.json`：官方网页与历史参考的可追溯证据索引。
- `motion-language.md`：真实动效线索与提出的交互动效语言。
- `specimen.html`：**原创设计观察样板**，不依赖网络，展示四种情境表达和可操作组件；不复制小米官网源代码、图片、Logo。

## 核心观点

以文字组织视觉，以编号和细线组织信息，以直接操作表达技术，以温和克制的界面留给内容空间。

建议查看 `specimen.html` 后再决定最终主题分支。此时不修改 SP，不提前锁定 Skin/HTML 适配接口。

## 证据等级与风险

A=官方页面，B=官方截图或更新说明，C=第三方历史截图，D=本研究提议。数值 Token、动画时长和示例页面均属于 D 级。
