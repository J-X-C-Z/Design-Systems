# MiMo 2.0 → Superior Point 适配约定

> 状态：**资源映射与行为约定已交付；未接入或修改 SP 代码。** 这里不是已部署功能说明。MiMo 是跨产品设计语言，SP 是它的一个消费者。

## 1. 保持分层

个人语言核心（身份、两分支、字体/色彩、动效、图形、参考）→ SP Adapter（语义角色与能力映射）→ SP Document（作品内容及编辑意图）→ reveal.js 放映与可编辑 HTML 导出。

不要把 SP 的固定画布坐标写回通用语言；也不要求所有 Research 网页都变成横版幻灯片。布局是作品创作，不是语言配置。

## 2. 映射表

| 通用角色/资源 | SP 消费方式 | 不应发生的行为 |
|---|---|---|
| ink / muted / subtle | 标题、正文、辅助信息的主题绑定 | 把品牌 Logo 或明确固定的语义颜色一并覆盖 |
| canvas / surface / raised | 页面、信息分组及层级底面 | 强制所有内容装入卡片 |
| accent / focus / status | 强调、键盘焦点、状态与图表语义分别映射 | 混淆成功/失败色和装饰色 |
| Display / Body / Mono | 语义文字层级，按投影距离调整规模 | 直接把 Web 16px 当作投影正文字号 |
| Indexed content / quiet contour | 可选索引构图、原创装饰 | 要求每页都有编号和同一背景纹样 |
| index-trace / type-unfold | 页面开始、Fragments 或关键观点的揭示 | 每次翻页都重复播放全套效果 |
| evidence-flow | 基于真实节点和连线的分步解释 | 捏造因果顺序或仅用截图假装可编辑 |
| quiet-reframe | 同一对象跨状态或跨页连续性，可结合 Auto-Animate | 将“切主题”当作“自动重编排动画” |
| focus-aperture | 受控遮罩或图像聚焦，保留减少动态效果替代 | 使关键内容只能在播放某段动画时访问 |
| data-reconcile | 基于真实数据变化生成图表插值 | 用样例条宽冒充用户的数据 |

## 3. Skin 契约

切换只重算主题关联属性。保留内容、页序、分组、连接线、位置/尺寸、现有动画身份和时间线。显式覆盖保持。单次换肤可以整体撤销；字体导致的换行/溢出应提示，不静默缩字或删除内容。

Adapt 为明确触发的风格协调，可调整借入资源的材料和节奏；Redesign 为明确触发的重新创作，可改布局。三者不得混成一个“应用主题”动作。

## 4. 两分支不是双重锁定

`rational-humanistic` 与 `dark-tech` 共用语言身份。全稿主主题、页面/元素覆盖和跨主题资源引用可以组合。资源既能跟随宿主，也能放入明确的保留外观范围。借用一条动效不等于继承整个 MiMo。

## 5. 网页交互翻译成放映交互

Hover 是可选提示，不是触发关键信息的唯一方式。投影演示应有键盘/单击的明确步骤；复制命令可保留为交互但不作为主要叙事。长文分页由内容决定；小屏样例的自适应不等于 16:9 画布自动重排。

时间线由项目拥有。SP 选择 reveal.js、Fragments、Auto-Animate 或自己的统一执行器，MiMo 的通用运行时只作为参考/可选实现，避免同一个属性被多个动画引擎竞争控制。

## 6. 导出验收合同

默认导出可编辑、自包含 HTML：保存项目结构、绑定与固定属性、实际使用的语言快照、资源版本及动效实现；不只保存 themeId，也不把整座设计库打入每个文件。只含必要依赖，并保证断网时静态内容可读。

本资源包自有样例的 `mimo-editable-specimen` JSON 不是 SP Document。正式适配需转换，不应宣称只导入 HTML 就自动获得 SP 级图层编辑。本轮已提供原始 HTML/SVG 与参考 PNG，便于未来转换，但尚未执行该转换。

## 7. 强模型的使用边界

提供语言概要、例图、资源清单、可编辑源码；不规定固定的封面/目录/三栏顺序。允许 AI 以基础元素原创新页面和动效。使用资源的前提是服务内容，技术合法性、安全、保存与撤销由 SP 程序校验。

## 8. 接入完成时才检查的事项

实际 SP 适配需另行证明：对象可编辑；更换两个分支不改几何与数据；借入资源可独立撤销；至少一段节点/连线动画保留关联；SP 导出再导入保持绑定；离线放映包含被用资源。

这些是未来集成验收项，不用来否定本次已完成的独立设计语言发布。
