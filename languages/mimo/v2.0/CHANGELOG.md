# Changelog

## 2.0.0 · 2026-10-10 · 独立设计语言发布

从 v1.3 研究样板升级为可复用资源版本，保持原有语言身份及“两分支 × 三场景”。

- 完成理念、视觉身份、跨场景表达、语义色彩、CJK/Latin 字体角色、密度与图形材料规范。
- 将候选值转为个人版本的明确默认值；与官方观察分开，不冒充官网源码测量。
- 完成五种标志性、五种共享动效：实际播放、暂停、进度定位、重置、取消与减少动态效果。
- 补全按钮、输入、复制、弹窗、任务与取消、表格密度等可见状态及交互说明。
- Skin 工具保留布局、文本、显式覆盖和已有动画；提供独立语义解析及版本化快照。
- 提供三个场景的两分支共六个自包含可编辑 HTML、原始场景结构、原创 SVG、成对参考 PNG。
- 增加白名单 JSON 与 HTML 导出/恢复闭环，导入文本保持惰性，不执行上传代码。
- 发布开放的 AI 上下文和可选 Skill；不注册 MCP、不改 AI 客户端、不要求固定创作步骤。
- 提供 SP 适配约定，但未修改 SP 编辑器或其文档格式。
- 包含可重建源码和有证据的离线 Chromium 回归；限制与未覆盖平台列于验证文档。

历史 v1.x 可从本仓库 Git 历史恢复。2026-10-11 按用户要求，当前目录仅保留 v2.0 规范资源，移除旧目录、ZIP 和逐字节重复的根文件；六个样例、源码及原验证证据保持完整。后续改动应基于实际使用与反馈做增量，不必重新开始同一轮研究。
