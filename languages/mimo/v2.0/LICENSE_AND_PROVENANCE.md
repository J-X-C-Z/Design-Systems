# 来源与使用说明

本包是为用户个人设计资源库交付的原创分析、参数、HTML/CSS/JS、SVG 与验证材料。MiMo / Xiaomi 等名称用于说明参考来源，不表示官方发布、背书或授权。`Rational Technical Humanism / 理性技术人文` 是本库对设计理念的描述，不是另一套新增主题。

设计来源在 `evidence/references.json` 与手册中登记。本包不复制或重新分发小米官网源码、Logo 文件、官方产品插图、官方截图或字体文件。截图是本包原创样例的实际渲染；SVG 是本轮原创路径。官方视觉引用只保留链接和观察记录。

本包供用户复用、修改和产品适配。该说明不代替第三方素材的授权，也不为第三方资产再分发提供授权。公开发布时应保留非官方来源说明；加入新的字体、图片或组件时单独记录来源、版本与许可。此处不替用户决定整个 Design-Systems 仓库采用何种开源许可。

`kit/` 的运行代码未引入第三方前端依赖；构建脚本仅用 Python 标准库。Playwright/Chromium 是测试环境工具，不随包分发。系统字体名称只作为 CSS 回退声明，不包含任何字体二进制。
