# MiMo-inspired 2.0 · 组件与状态语言

> 组件是 optional 资源，不是页面拼装的必选清单。下表描述本版本实际样板与可复用原型；产品业务、后端任务、云端保存不在此库实现。

## 1. 总体表达

以轻界面承载强内容：需要分组才出现表面，需要边界才出现边线，需要行动才强化按钮。编号、短标签和箭头组织阅读，不将所有内容做成同尺寸大圆角卡片。长时工作界面用适当密度；研究封面可以大字留白。两者共享字体角色、颜色语义和状态原则，不共享固定几何。

## 2. 十二类模式及状态覆盖

| 模式 | 本版可见状态/行为 | 键盘与反馈 | 复用注意 |
|---|---|---|---|
| Primary / Secondary Action | 静止、悬停、焦点、按压、禁用、忙碌 | 原生 button；忙碌文本+aria-busy；实际操作后反馈 | 禁用不通过低对比文字表达唯一信息 |
| Indexed Link Row | 编号、标题、元信息、箭头；hover/focus定向变化 | anchor 可键盘访问 | 不给每行都加不同动效 |
| Command Strip | 平台切换、命令、复制成功/失败 | tabs 支持方向键；复制失败提供手动选取 | 示例只复制 `node --version` / `python --version`，不执行命令 |
| Form Field | 空值、编辑中、错误、修正、通过 | label、aria-invalid、错误文字、错误后焦点返回 | 不清空用户输入；检查只是本地示例 |
| Segmented / Tabs | Research/Developer/Workspace、两种平台 | roving tabindex；方向/Home/End；aria-selected | 内容隐藏保留结构；切换不等于另建项目 |
| Disclosure | 原生 details/summary 开合 | 原生键盘操作 | 不为简短内容强制加折叠 |
| Dialog / Inspector | 打开、关闭、Escape、焦点恢复 | 原生 dialog/showModal | 重要内容不是仅鼠标可达的 hover 浮层 |
| Toast / Inline Feedback | 明确收到操作、复制失败、导出提示 | 文本状态区域提示 | 反馈不假装等同于持久化保存 |
| State Badge | 普通、成功、警告、失败、处理中 | 文字+形态，不仅颜色 | 数据含义来自业务，主题不改语义 |
| Table / Data Surface | 标题、字段、数值、舒适/紧凑密度 | 原生 table；小屏容器横向滚动而非页面溢出 | 表格局部滚动是有意边界，不隐藏列 |
| Prompt Composer | 可输入、建议填入、空值校验、运行、取消 | 原生 textarea、按钮；输入保留 | 演示不连接真实模型，结果明确标注 |
| Task Progress | 开始、步骤推进、完成、取消、结果区 | progressbar + 状态文本；取消后停止定时器 | 产品适配应以真实事件驱动，不用假计时伪装后端进度 |

## 3. 功能色与边界

正文采用 ink，辅助信息 muted，低优先元信息 subtle。rule 是静态装饰分隔，不应单独承担重要交互的可识别边界；输入与选择器需要 control / focus。成功、警告、错误不能只有色彩差异，配合明确文案与图标/形态。

本版对 50 个指定语义色组合进行了数学对比度计算，具体数值见验证记录。不是对全部合成色、照片背景或后续任意自定义内容的无条件承诺。用户将文字放在图像上时，需要重新判断实际背景。

## 4. 状态文案

优先解释下一步，不用虚构的“系统很聪明”式文字。例如复制失败应说“浏览器未授予复制权限，请手动选择并复制命令”，而不是播放打勾。取消应明确“已取消，输入仍保留”。下载仅代表文件已经生成并交给浏览器保存，不代表已经写入用户选定硬盘或同步云端。

## 5. 可编辑性与持久化

展示台的“编辑文字”开放白名单文本区域。修改文字、场景、视觉分支可以导出 JSON 和自包含 HTML 并重新打开。原始 HTML/CSS/SVG 也是可编辑源码。这里的可编辑不等同完整可视化布局工具；工作区输入、演示任务、收藏计数等交互状态不会全部成为导出项目数据。

此限制是明确的产品边界，避免误把实验台当作 SP 编辑器或云端应用。

## 6. 响应式策略

宽屏可以并置内容和证据；中屏重分配主要内容；紧凑屏回到单列，工具栏换行，表格仅在自己的数据容器中滚动。实际样板验证 1440 / 1024 / 390 / 320 CSS px，以及中文和长英文内容。断点是个人实现默认，不是从官网精确提取的值。

不同操作系统字体差异会影响行数；不可用固定高度假装字体永远一样。新增组件应为内容增长预留空间。
