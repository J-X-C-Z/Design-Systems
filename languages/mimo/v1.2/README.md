# MiMo-inspired Design Language — Research v1.2

个人独立设计资源库，原始观察与衍生设计分开记录；不是小米官方规范，也不是 SP 主题文件。

## Contents

- `MiMo_Design_Language_Study_v1.2.md`: 完整研究报告与证据边界。
- `evidence-register.json`: 官方来源与已确认 / 未确认字段。
- `style-matrix.candidate.v1.2.json`: 可用于多个场景的候选规则（非生产 CSS）。
- `MiMo_Design_Language_Lab_v1.2.html`: 离线单文件交互实验台。
- `preview/`: Playwright 实际渲染的截图及验证报告。

## Use

双击 HTML，在网页中切换视觉模式 (Rational Humanistic / Dark Tech) 与场景 (Research / Developer / Workspace)。第 04 章有动效行为实验，第 05 章实时计算候选文本配色对比度；也可以下载当前组合的候选 JSON。

## Principle

一个设计家族 × 两种视觉模式 × 三种场景语法。动效解释真实行为，实例提供参考但不限制 AI 创作。官方源代码、字体或品牌素材未打包。
