02
Design system extracted by comparison

身份稳定，场景变化。

把视觉模式与内容场景拆开，才能避免将不同网站硬塞进一张模板。所有色值和时长都属于候选值，尚未实测生产 CSS。

LANGUAGE / NOT A TEMPLATE

纸面明度、精准字阶、克制的线和温和负空间。面向阅读和操作的轻盈表达。

VISUAL MODE 02

Dark Tech

中性深色材质、清晰层级和局部动作焦点。不是高饱和赛博霓虹设计。

04
Stateful motion · original hypothesis

同一种节奏，服务不同任务。

将「理性人文 / 暗黑科技」作为视觉状态，将 Research / Developer / Workspace 作为信息任务。观察动效如何强化阅读路径、复制反馈和任务进度。效果与数值均为原创候选，而非官网动效采样。

05
Proof before polish

先核验，再固化 Token。

06
Provenance & boundaries

可追溯，也要保持独立。

信息架构和官方命名来自公开网页；候选色值、组件样板和动效为原创推导。不会打包第三方字体、Logo、品牌图片和页面源码。

MiMo Studio 官方发布记录仅证明其产品引入「理性人文 / 暗黑科技」两种视觉方向，不证明所有 MiMo 官网都共享这套全局主题配置。跨站点 Design Language 是独立归纳。
