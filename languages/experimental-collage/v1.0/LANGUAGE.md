# 实验拼贴：有意的断裂
## 类型与增量
拼贴的核心不是“歪斜纸片”，而是来自不同语境的片段形成新的冲突、比喻或问题。它与编辑杂志共用文字/图像，但主动暴露接缝；与低技术可见基础设施不同，暴露的是意义和材料的重组；与 Y2K 数字贴纸不同，不依赖特定年代的高光、界面或网络符号。与漫画不同，阅读可多入口，但必须有可找到的主锚点。

## 四层
核心：异质片段、决定性并置、清楚的接缝与阅读锚点。
配置：纸上论点 / 图像超现实 / 文字实验。材质和角度可变，意义关系不可缺失。
资源：剪切边、圆形裁片、标签、套印偏移、手写线与证据注释；不是所有画面都必须用完。
适配：海报可高对比且大形；长文必须转回稳定正文；互动舞台只解释重组关系。

## 生成语法
写出要提出的问题 → 选两类有语义距离的材料 → 指定一个共享点（形/词/方向）→ 切断原关系 → 建立一次新的接触或遮挡 → 加阅读锚点 → 检查是否仍可解释。若只能用“有感觉”说明关系，应返回材料选择。

### R1 片段具有语义，不是噪声
依据：MoMA 对 Höch 从大众媒介重组图像并形成批判关系的阐述 [E1,E2]。本包不挪用历史作品的政治含义。
做法：每一类片段写下来源与作用；建议 2–4 类，不按元素数量堆密度。
正例：岸线曲线与时间刻度并置，提出“记录如何切分时间”。反例：随手贴眼睛、花、机器和日文，只因“很拼贴”。
允许：意义可以开放，但至少存在可说明的连接。验证：作者能用一句话说明两片为何相遇。

### R2 主锚点和局部混乱共存
最大文字或主要轮廓担任入口；其他片段围绕一条斜向/弧向路径排列。正文区不倾斜，保留可连续阅读的解释。
允许：局部遮挡主图，不遮挡标题关键词与行动信息。正例：大字“重新看见”与一个穿透圆；反例：所有纸片同样大、所有文字都旋转。
验证：缩略图能找到入口；放大后能找到论点与来源。

### R3 接缝要被看见
纸片之间可用裁切边、轻阴影或材料差异显示重组。只选一项主接缝手段，不同时堆撕边、胶带、重阴影、噪点和折痕。
A 参数：纸片旋转通常 ±3–8°，重要文字保持 0°；边界阴影 3–6px，避免像悬浮塑料 UI。
正例：不同纸色和错位的边缘；反例：每个片段都套同一种圆角卡片，消除了材料差异。
验证：灰度下接缝依然清楚；手机转为叠放仍保留语义关系。

### R4 变形针对关系，不伤害事实
比喻图形可放大、旋转；数据比例和真实引语不能为了构图篡改。照片重组涉及人物时需审查误导、肖像与上下文。
正例：明确标“概念图”的抽象岸线；反例：把真实人物与负面事件拼合，却不标虚构。
验证：素材清单区分事实、引用、概念与原创片段。历史艺术的挪用实践不自动授权商业再使用。

### R5 动作像剪辑，不像果冻
来自 NFB 剪纸逐格过程的技术启发 [E3]；本包以有限位移、突然停顿、层级交换体现重组。
做法：每次控制改变一项关系；240ms steps(3,end)，终点稳定；不震动正文、不快速闪烁。
正例：圆片从独立变为压住纸条；反例：所有片段无限弹跳，用户找不到稳定读点。
验证：每一终态独立成立；快速前后切换不累积偏移；减少动效直接切终态。

## 三个分支
纸上论点：文本条带、资料片段、注释，适合观点海报。
图像超现实：两类物件发生不可能但可解释的关系，适合文化传播；必须标概念。
文字实验：尺度、字重、剪断与重排为主体；中文切分遵守语义，不拆字到无法辨认。

## 同内容与迁移
岸线观察内容做海报、拆解舞台与正文，复杂度来自观点关系而非控件数量。新的“城市声响档案”用波形条带和时间标签替换岸线，保留片段/并置/注释语法。数字 12 点位、3 轮记录、30 分钟是虚构计划，不以错位图形暗示数据关系。
