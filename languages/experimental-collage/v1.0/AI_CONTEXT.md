# AI 创作协议
先说明“哪些片段因何相遇”，再选材料。读 LANGUAGE / EVIDENCE / MOTION；现有示例不是允许任意套图的模板。
创作提示：用原创抽象岸线、时间纸条和记录标签表达“观察如何切分时间”；做海报、正文页、三步重组。每个片段提供语义标签。
迁移提示：为城市声响档案重组波形和钟面，不能直接换海报标题；解释主锚点、接缝与冲突怎样对应新内容。
自检：材料来源可查；概念图不冒充事实；关键正文不旋转；缩略有入口；手机有完整文字替代；运动不闪烁且终態可读。需要真实人物或版权图像时先核实授权。
禁止用文化符号作无语境异国装饰，不把历史批判作品的形式剥离成对群体的刻板印象。
