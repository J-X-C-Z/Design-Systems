# 重组的时间语法
舞台三态：片段独立 → 发生遮挡 → 加入注释。按“上一步/下一步/重置”改变 data-scene。每态都显示一个完整句子，操作不依赖拖动。
对象只包括三片原创材料。位移 20–70px / 600px 画幅、旋转至 ±7°，240ms steps(3,end)；文字解释无移动。有限分段提供剪辑感，不使用频闪或抖动纹理。
连续点击的 CSS transition 从当前显示值指向新终态，不创建队列。重置回独立态；无自动播放或背景动画。按钮边界禁用并写 aria-live 当前阶段。
减少动效：transition:none，直接显示终态。无 JS：默认海报与三个阶段文字均可读。窄屏：舞台尺寸缩放，详细文字放在画框之外，不随图形变小。
性能：三个 transform，零定时器和零动画循环。投影/视频改编需重新检查闪烁与可读时长；本包未生成影片。
