# 沉浸空间 / Immersive Space 1.0
用视点、阈限、地标与返回路径组织内容，让人知道自己在哪里、正看什么、如何离开。
主类型：空间与沉浸叙事；辅类型：展览传播。交付是离线浏览器中的二维/2.5D 概念样例，不是 VR、AR 或真实展厅工程。

打开 `specimen.html`：入口→观察室→资料室三站，可返回入口、切换平面阅读、查看完整文字版。还有空间路线图与“夜间图书馆”迁移样例。`space.svg` / `route.svg` 是原创可编辑概念资产。
核心/来源/运动/参数/AI/适配分别见对应文档，VALIDATION.md 清楚划分已做与未做验证。无相机、麦克风、位置、头部追踪或音频权限。
