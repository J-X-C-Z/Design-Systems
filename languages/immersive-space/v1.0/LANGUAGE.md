# 沉浸空间的设计语言
## 对象与边界
空间通过距离、遮挡、尺度、朝向和路径组织意义。大背景图或满屏视频不自动构成沉浸语言。与生成艺术相比，核心不是图像规则的多样输出，而是参与者和空间的关系；与建筑拟态页面不同，不为所有链接画一个房间；与玻璃界面不同，不把透明材质当作空间本身。

## 四层系统
核心：定位、注意、阈限、路径与退出权。
配置：建筑阈限、环境场、物件剧场三个分支，不能把它们全部理解为黑底霓虹。
资源：入口视图、路线图、地标、阅读锚点、分站叙事；可依据内容替换房间与物件。
适配：网页2.5D、投影、展厅和头显各有技术与安全条件。本包只实现网页概念。

## 生成语法
定义体验终点 → 列出必要停留点 → 确定进入与退出 → 给每站一个可辨地标 → 安排一次主要注意方向 → 让移动解释内容变化 → 提供平面等价阅读。先设计路径，后选材质和灯光。

### R1 每一视点都能回答“我在哪”
依据：Apple 对环境、接地与舒适性的指导 [E3]；本包地图与站名是原创适配。
做法：持续显示站名/进度/返回入口；地面或水平线提供参照。移动时不突然反转世界方向。
允许：艺术作品可探索，但内容访问界面不隐藏退出。正例：观察室 2/3 + 返回入口；反例：全屏自动飞行，用户不知是否能停止。
验证：只看界面文字也知道当前位置与下一步。

### R2 阈限建立节奏
入口压缩信息，主空间放开视野，资料空间恢复阅读密度。门、光带、边界或声场变化可以表达章节转换，不必画真实门。
A 建议：三站概念样例使用近/中/远三层，主景居中；一个页面至多一个主转场。
正例：从入口看见远处亮面，再在观察室呈现内容；反例：每个滚动像素都改变相机，让正文无处停留。
验证：静态三帧也能解释叙事先后。

### R3 近处可操作，远处可观看
可操作对象要有清晰边界、文本/图标与焦点，不要求人猜测远处光点是不是按钮。画面的拟真大小与控件实际命中尺寸分离。
正例：场景外固定控制栏，场景内地标只作叙事。反例：只有鼠标悬停才出现的隐形热点。
验证：Tab能操作全部功能；触控和键盘不需要精确空间运动。

### R4 运动不剥夺身体控制
依据：Apple 的舒适和免强制身体移动指导；实体案例 [E1,E2] 仅启发空间关系，不作为网页可达性依据。
本包不追踪头部、不绑鼠标视差、不自动移动相机；点击后轻量景深/明暗变化，450ms，最大缩放1.06。减少动效直接切换。
正例：用户随时选择平面阅读；反例：模拟头部漂浮、周边持续快速光流。
验证：停止/返回在任意站可用；无转场锁屏与焦点陷阱。

### R5 氛围支持内容，不掩盖内容
环境纹理和光线在阅读区之外；正文用实底，高对比，不能依赖透明玻璃后方恰好是暗色。每个场景有说明与平面替代。
正例：观察室场景说明“12点位/3轮/30分钟，为虚构计划”；反例：在亮面上叠细白字并用沉浸感解释不可读。
验证：切平面模式后内容与导航完全不变。

## 三个分支
建筑阈限：嵌套框景、地面、门槛与体块，已实现概念视图。
环境场：雾、光、密度和方位暗示连续世界，需额外性能与舒适性验证；未实现实时环境模拟。
物件剧场：一个物件随叙事变化，固定观众视点，以灯光和局部转向聚焦；可用于产品故事，未实现3D物件。

## 内容检验
岸线观察三站：入口给问题，观察室给方法，资料室给限制。12点位、3轮、30分钟作为虚构计划保持不变。新内容“夜间图书馆”采用走廊→阅览桌→目录，不借海岸材质维持身份；路径、地标和等价阅读才是共享语法。

## 不适用与文化边界
支付、报错、法规文本不应藏在沉浸叙事中。现实展览有真实动线、无障碍路线、消防和容量要求，概念图不构成合规方案。不能未经许可复制艺术家标志性房间、灯光编舞和互动作品。
