# 阈限与返回
点击站点按钮改变当前站，更新文字、aria-pressed与空间data-room。舞台只用三个稳定层：近框、中框、远景；不同站改变两框的有限scale与opacity，450ms cubic-bezier(.2,.7,.2,1)。最大scale1.06，远景不持续移动。
目的：提示“注意层级改变”，不是模拟真实步行速度。没有鼠标跟随、滚动劫持、陀螺仪或自动巡游。
返回入口：立即更新状态，CSS从当前视觉值向入口终态过渡，不排队、不禁用退出。平面阅读：移除景深变化，三站文字仍在原文档中。切回空间不改变站点。
减少动效：禁用所有transition，并提供平面阅读选项；空间仍可静态展示。无JS：入口和完整文本已在HTML，导航锚点可读。无声音默认，不添加假“静音”开关。
性能预算：仅有限transform/opacity；没有WebGL、Canvas或高分辨率纹理。没有持续计时器。真实头显舒适、手机GPU与屏幕阅读器未测试，不能宣称XR ready。
