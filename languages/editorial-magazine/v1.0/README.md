# 编辑杂志 / Editorial Magazine 1.0
用标题、正文、图像、旁注和翻页节奏，让复杂内容成为可进入、可深读、可回看的故事。

主类型：编辑出版与演示；数字叙事为辅。适用专题报道、文化期刊、研究特刊与长文；不是通用后台组件皮肤。

离线打开 `specimen.html`：封面→目录→长文→三段证据解读→迁移栏目→编辑正反例。CSS、内联 SVG、脚本均可编辑，无外部依赖。
`LANGUAGE.md` 定义核心与三个分支；`EVIDENCE.md` 保留参考及边界；`tokens.json` 给出原创建议参数；`MOTION.md` 说明阅读型动效；`AI_CONTEXT.md` 与 `ADAPTATIONS.md` 支持后续创作；验证结果见 `VALIDATION.md`。
所有报道、地点、数字均为明确标注的原创虚构内容。未复制参考杂志封面、照片或字体。
