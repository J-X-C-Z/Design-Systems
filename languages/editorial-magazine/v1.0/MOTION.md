# 阅读运动
主运动是“编辑聚焦”，不是全页淡入。
触发：点击三段证据标签；对象：当前标签下的 2px 规则线、条形图对应条目；前态：无强调/上一次条目；后态：新条目以实体轮廓和加粗标签突出；180ms ease-out 的边线扩展仅表示焦点。
完整文本与所有数值始终可见，不因切换隐藏。按钮保留焦点，aria-pressed 与视觉同步。连续点击立即替换目标，不排队、不自动播放。返回前节使用普通锚点，无 JS 也可导航。
旁注使用原生 details，开合无高度动画；这避免长文重排中无法控制的跳动。用户可以直接关闭。
减少动效：移除所有 transition/animation，强调仍由轮廓/字体表达。打印：不输出操作按钮，保留全部证据与旁注文字。没有背景循环、滚动劫持或视差。
性能预算：零外部请求、零持续计时器，一次点击更新三个按钮与三个条形项。sticky 仅用于宽屏栏目标题，窄屏和打印回到流式布局。未声称在所有浏览器完成性能测试。
