# 媒介适配
网页：优先语义 article/section/figure/figcaption/aside。不要将纸刊的跨页装订关系强行搬到手机；窄屏根据阅读顺序叠放。正文可选中、缩放，链接可辨认。
PPT / SP：把长文拆为论点、证据、限制三类页；继承标题/导语/图注角色与章节节奏，不复制 19px 屏幕字号。每张图有来源，不让动效承担唯一解释。
印刷：对开页面可使用不同版芯，但语义阅读顺序保持；检查孤行、图注与图片分离、出血和装订。此包打印 CSS 只是起点，未交付印厂 PDF。
可达性：按钮至少 44px，正文暗墨对浅纸，焦点有实线；图表同时提供数值文本。真实用户测试、屏幕阅读器和纸面打样仍需补充。
