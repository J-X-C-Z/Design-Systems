# 编辑杂志的语言核心
## 独立性与边界
编辑杂志的身份来自“阅读速度的变化”：封面吸引、目录定位、正文展开、图表举证、旁注校正、结尾回响。与瑞士信息设计共用网格，但允许文字声音、跨栏图像和章节节奏改变视觉中心；与实验拼贴不同，意义依赖连贯阅读，不以冲突和断裂为主；与漫画叙事不同，不依赖分镜或角色连续动作。

## 四层结构
核心是编辑角色与阅读顺序；配置是文学、观察、视觉特刊的口吻；可选资源是引语、边栏、目录、跨页图、图注；产品适配处理屏幕、投影与印刷。一个专题可不用衬线体，也可不用照片，只要叙事角色与节奏仍成立。

## 从素材到版面的生成过程
写出报道问题→列出证据与限制→编排三到五个叙事节拍→指定每个节拍的阅读速度→分配正文/图像/旁注→再决定网格。不能先挑大标题模板，再让内容硬填。

### R1 标题是一项编辑承诺
目的：告诉读者文章能回答什么。依据：Pentagram 对主题与变化的讨论 [E1]；具体字数为 A 原创。
做法：标题表达问题或观察，导语交代对象、时间与限制；封面最多一个主承诺。建议中文主标题 8–22 字，可为语义断行，不为造型拆散词组。
正例“海岸退去以后，观察者留下了什么？”反例“重新定义未来”配无关数据。
允许：文学标题可隐喻，副题必须补充语境。验证：只读标题和导语能判断内容边界。

### R2 固定角色，变化构图
正文始终是正文，图注始终说明图片；章节中可改变占栏和留白，不能让同一视觉角色任意换意义。大图不必每两页出现，节奏由论点复杂度决定。
正例：同样的 14px 无衬线图注穿过不同版式。反例：某页小斜体是作者、另一页小斜体是结论，且无标签。
验证：把三种不同结构并列，角色仍可识别。

### R3 正文优先于视觉戏剧
默认屏幕正文 19px/1.9，中文行宽约 24–34em；长文使用自然段，不制造狭长三栏。标题可 3–5 倍正文，但不能侵入正文行盒。正文段落间距统一，章节间距明显更大。
允许：纸刊在足够幅面使用多栏；手机一栏。正例：导语宽、正文窄、边栏独立。反例：小屏硬保留双栏或用全大写英文挤占中文正文。
验证：150 字长段、三层标题、长英文词与来源链接不截断。

### R4 图像必须承担编辑角色
标明是证据、现场记录、解释图还是概念插画；概念插画不能冒充现场照片。数据图表选择取决于比较任务 [E3]，不能只挑“好看”的形状。
正例：三次复测数据用共同零点的条形长度和数字；反例：将 12/3/30 画成同等大小圆并声称可比较。
验证：隐藏装饰后仍有事实可读，图注说明数据来源和限制。

### R5 节奏不是强制滚动
数字长文的运动只帮助解释次序；全文可线性阅读，图表关键结论不只藏在滚动状态里。旁注展开不抢焦点、不跳转位置；减少动效时保留顺序。
正例：三段文字一直可见，按钮只强调对应证据。反例：要求用户逐段滚动才能看到正文，或屏幕锁住播放。
验证：关 JS 后仍可读完整论证；快速切换无旧动画拖尾。

## 三个分支
- 观察型期刊：清晰无衬线标签、较大的事实图、简短旁注，适合研究/公共议题。
- 文学型期刊：较长正文、更大的内文呼吸、少量衬线标题与节制图像，适合访谈/随笔。
- 视觉特刊：跨栏主视觉与强标题比例、稀疏短文，适合摄影/文化专题；不能挪用于高密度说明而删掉证据。
三分支共享刊期、栏目、署名、图注与来源等角色，字体选择不等于整个语言。

## 同内容与新内容检验
同一岸线观察主题分别生成封面、目录、正文与数据解释，不重复卡片布局。迁移内容“修复一把旧椅子的时间”改用工序旁注和材料清单，保留编辑声音与阅读节拍，不保留海岸图形。所有内容为原创虚构，不能当作实地报道。
