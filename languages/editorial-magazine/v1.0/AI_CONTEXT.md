# 创作协议
先从任务和材料出发，读 LANGUAGE.md、EVIDENCE.md，再使用 tokens.json；不要把 specimen.html 当成固定拼装模板。
输入：主题/编辑问题、读者、证据、篇幅、媒体、可信限制。先给叙事节拍与每段要证明的事，再排版。选择观察型、文学型或视觉特刊；不把多种标题风格堆在同一期。

新内容提示：将“社区旧椅修复记录”排成开篇、工序长文、材料旁注三个不同结构；保持角色系统；不得编造真实采访或引用。标记示例内容。
检查提示：找出标题过度承诺、图注缺失、图表非共同基线、窄屏硬分栏及只在动画中可见的论点，并给出修复。
允许扩展：新的章节角色可添加，但说明它与正文/引语/图注的区别；新字体须验证中英文与许可。禁止：用品牌封面作底图、假署名、无来源的引语、把装饰图当证据。
交付前列出已验证和未验证项目，不把文本提取当视觉验收。
