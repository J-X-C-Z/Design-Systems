# 模块关系的铰接运动
三态：分立→连接→节奏。按钮立即更新解释；同一组三个几何形在画布中有限位移/转动，360ms cubic-bezier(.25,.7,.25,1)。转动原点固定在各自接点，最大12°，无弹簧过冲。
动效表达模块如何改变关系，不模拟真实力学平衡。每个终态可单独印刷。没有自动循环、鼠标跟随或背景晃动；连续点击由CSS追踪新目标，不创建动画队列。
复位回分立态；减少动效移除transition直接显示当前构图。无JS保留默认画面与三态文字；用户不用解读动作才能理解内容。
纹样展示静态，不将每个单元都转动。若视频改编需另写镜头长度与节拍，不能把浏览器默认时间当历史原作节奏。
预算：3个transform，不用canvas/webgl/外部资产；真实浏览器和低端设备性能未验收。
