# 创作协议
先定义信息角色和形的关系，再选中期现代分支。读 LANGUAGE/EVIDENCE/MOTION/tokens；不要照着历史名作描边。
提示：为虚构岸线观察日做海报、说明折页和一个模块关系演示；用圆、桥、杆三类原创形，保留12点位/3轮/30分钟的文字含义。
迁移：为日常阅读周创建目录和重复纹样侧栏，保持形/色/留白关系，不把海报内容直接换标题。
扩展：允许新的主体与纸色，但应说明基本形如何组合，纹样如何重复/裁切/收束。新字体要验证中文和许可。不能借民间图样的名义复制未经授权文化资产。
自检：去纹理仍成立；主次清楚；重复可解释；长文稳定；没有以怀旧为由降低对比；动效可减且终态可印；历史范围和测试范围准确。
