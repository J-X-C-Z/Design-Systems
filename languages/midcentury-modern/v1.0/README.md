# 世纪中期现代 / Midcentury Modern 1.0
以简化形、色块关系、轻快的不对称和可组合模块，把日常事物组织成清楚而有生命力的画面。
主类型：品牌视觉、编辑与装饰；辅类型：解释型运动。研究聚焦若干美国中期现代设计案例，不宣称代表全球同一时期全部现代主义。

打开 `specimen.html`：观察日海报、模块编排实验、内容折页、阅读活动迁移与正反例。`composition.svg` 与 `pattern.svg` 是原创可编辑几何资产；没有复制 Girard、Eames 或其他历史图样。
文档与参数按 LANGUAGE/EVIDENCE/MOTION/tokens/AI_CONTEXT/ADAPTATIONS 组织。实际测试范围见 VALIDATION，静态SVG检查见 SVG_REVIEW。默认离线、无动画循环、无外部字体。
