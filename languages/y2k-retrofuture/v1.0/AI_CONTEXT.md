# AI 创作协议
先判断内容是否适合媒体物件感。读 LANGUAGE/EVIDENCE，选一个主分支，再使用tokens与MOTION。别把“Y2K”当所有复古界面的名字。
提示：给虚构岸线观察资料做数字光盘封面、三章节目录和活动票；不放历史品牌，不播放声音，不使用假加载。
迁移：为夜间信号文化活动设计票面，用轨道和胶囊组织时间/主题，但将所有正式信息放在稳定实底。
扩展：允许新材质色、原创轨道形和不同主标题比例；保持正文对比、按钮语义与短促可停运动。主题变化不得改变数据/功能。
自检：历史来源清楚；没有混淆时代；关渐变仍有层级；中文字未压扁；控件有真实用途；没有未经授权素材；减少动效和无JS完整。未实测结果不能写兼容/流畅通过。
