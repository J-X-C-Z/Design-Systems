# Aurora historical layer: original12

Preserved source for 12 historical candidate identities. This is a separate package/application, not an integrated extension of the current repaired module. This historical layer was not rerun with the current repair. Its original behavior and validation limits remain unchanged.

Source, required authored assets/tokens/styles and licenses are retained. Generated bundles, vendored dependency copies, old screenshots, archives and machine-specific logs are excluded. This is a source preservation snapshot, not a newly built or browser-accepted release.

Aurora original12 used React 16.0.0 and a pinned TypeScript-based offline bundler; Paperclip original22 used React 19.1.1, D3 and a TypeScript 5.8.3-based offline bundler. Their large vendored compilers/runtimes and custom build scripts tied to those copies are not included. Supply the appropriate dependencies and a JSX/CSS/JSON/SVG-capable bundler to consume these source applications. Historical package scripts may refer to omitted tooling and are retained as metadata, not a promise that npm scripts work in this trimmed snapshot.

Bauhaus/Collage actions layers contain three button candidates; FlatVector actions contains four. Their portable build entrypoint is retained where present; create the required output/qa directories and set LOCAL_DEPENDENCIES to an existing toolchain. Cel's two historical selection components remain separate from the current repaired four-component package. No Cel48 editor candidate is included.
