# 七种独立表达，而不是七张换色工作台

## Echo / 回声印务所

以原包 Echo 纸感、墨色、橙色、硬边阴影为基础，改成“宣言—实时纸张校样—排版编辑—纵向档案”的印务所。字级与留白是主视觉，不用仪表卡片。SVG 真正绘制文字/网格/圆形，输入、字重、对齐即时更新；保存与导出是不同动作。桌面双栏在手机变成先看作品、再编辑的顺序。英文采用较硬的系统无衬线，中文明确控制换行和三行限额。

来源：包内 `source-original/Echo-Design-System.html`。没有凭空增加外部作者/产品链接。

## Bloom / 每天长一点

绿色、天空蓝与浅黄只服务于学习反馈；主布局是一条有前后解锁关系的曲线路径，而非表格。原创小芽角色代替第三方吉祥物；圆角、厚底按钮与轻微呼吸构成亲和感。做错可以重试，完成过的关卡可复习但不重复加 XP。手机保留关卡纵向节奏，将每日目标放在路径之后。

来源：https://www.duolingo.com/ ，并复核原包 Bloom 样式。当前网页正文可读内容有限；没有原站动作逐帧复刻或官方身份声明。

## Neuro / 本地信号观察站

黑灰底、琥珀强调、低密度扫描线和等宽数字，采用“一条信号—参数边界—事件带”的工具结构。曲线由频率/相位生成，开始/暂停、单步、白名单命令、故障诊断与日志导出都有可见回应。这里的功能是模拟器，不是假装真的接入服务器。减少动效时连续采集的画面停止，单步观察仍可用。离开页面不保留活动采集任务。

来源：包内 `source-original/Echo-Design-System.html` 的 Neuro 基线。没有把另一个同名品牌当作来源。

## Follow / 创作发生现场

橙色宣言、大尺度文字、轨道印章、交错的作品长页，营造开放的策展阅读节奏。作品不放进重复的小卡网格；第二件作品在桌面反转图文次序，小屏恢复阅读顺序。收藏和类别筛选直接改变展出内容，联系入口只形成可导出的本地草稿。三组几何作品、项目名称与演示作者均为原创设定。

来源：https://follow.art/ ，以及包内 `site/echo-latest/follow-source.json`。保留观察到的橙色与纸张/灰绿气质；Hardbop、HeadingNow 未取得可分发字体，不宣称字形相同。

## Wix / 五页材质册

以 Mocha Mousse 的暖棕和奶油底为中心，采用五个可扩展的材质页。层叠球、石块、丝带、泥环、纹理柱由 CSS 原创生成；尺寸、颗粒、色样会改变呈现。不是上传材质图后的静态相册。配色方案、复制失败提示、去重色样夹和 Token 导出让美学研究可操作。手机变成纵向展开书页，不压缩五列。

来源：https://www.wix.com/studio/pantone-color-of-the-year-2025 。官方正文可确认的 #A47864 / #A67763 分别保留在研究与配色里；非官方色彩许可产品，未取得 Madefor 字体或原站材质资产。

## Maigawara / 有机轮廓游乐场

粉底、绿线、橙色竖栏，主视觉是一张可生长的海报。层数、幅度、旋转、环形文字、模式同时驱动 SVG。轮廓不完全对称，导航和控件像海报边的工作条，不是功能卡片。拖动与方向键是并列输入方式，收藏以参数组去重。手机把竖栏放到海报下方，保留夸张构图。

来源：https://maigawara.com/ 及包内 `theme-source/expressive/sources.json`。本次网页访问没有取得可读正文，主要依赖随包既有视觉观察与源码；不能声称已完成最新站点视觉核验。

## GOONS / 会回应的空间装置

雾灰舞台、大白字、蓝色体积、橙色胶囊与局部玻璃条带。先体验物体，再阅读项目索引；采用 CSS 三维变换，而不是视频背景。物体选择、双轴拖动、键盘视角、玻璃强度和重置都会改变舞台。项目详情与咨询草稿独立于装置状态，关闭弹层会取消未完成的本地任务。

来源：https://goonsdesign.com/ 及包内 expressive 来源记录。官方正文可读，当前未做现场截图逐像素比对。无原站照片、3D 模型、视频或真实客户案例；不把 CSS 体积称为 WebGL 模型。

## 可复用但不抹平差异

复用的是状态、语义、焦点、取消和基础组件，不是七页的空间骨架。公共顶栏仅承担返回目录、风格切换和减少动效；它不主导展示页布局。

`tokens/*.json` 的语义色、文字回退、边角、阴影、缓动独立维护。页面色彩集中为 `paint-*`，键名是原始色值指纹；页面 CSS 负责构图、响应式和材质结构。SVG 作品由 `art.jsx` 渲染，明确区分原创图形和外部参考。未附带字体文件；缺少指定字体时回退本机字体，不声称跨平台字形一致。
