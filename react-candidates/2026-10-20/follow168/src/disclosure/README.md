# React disclosure slice: three exact source candidates

Exports: `Tabs01`, `Accordion01`, `Dialog01`, `tabs01Items`, `accordion01Items`, `normalizeDisclosureItems`.
Import `styles.css` once under the shared seven-theme Provider. Components render real React trees with useState/useRef/useLayoutEffect and keyed controls, not a native adapter mount or HTML string. There is no imperative `mount/update/getState` API; ordinary React props and refs own the lifecycle. The original seven-theme Native DOM products are reference material only, with no inherited React acceptance.

## Exact source differences

- Tabs01: overview/roadmap/backlog, initially overview. Horizontal automatic activation; source prose has one emphasized phrase in each panel. Source rounded track becomes token-driven Follow square/colored track. Native React text nodes and strong preserve paragraph structure. Manual activation and RTL are explicit extensions.
- Accordion01: multiple simultaneously open entries, initially item-1; all may close. The upstream primitive uses leading ChevronDown/ChevronUp, not plus/minus. ArrowUp/Down/Home/End only move focus. Each panel has its own label/control references.
- Dialog01: source AlertDialog has one visible trigger, title, description, Cancel/Continue and no X. Pointer outside does not close. Its primitive is Radix's modal portal; this adapter intentionally uses the browser's native HTMLDialogElement modal top layer in the same React tree, inheriting Provider CSS variables. No forced last-control-to-first-control Tab trap. Native modal background isolation, browser chrome reachability, initial focus, close event timing and focus restoration need real-browser review. The source nests a Button inside an AlertDialogTrigger; this adapter renders exactly one native button, avoiding nested buttons. Continue does not delete an account or contact a service.

The exact three TSX sources plus four direct base primitives are saved under sources. Source identities have been independently recomputed as Git blobs against canonical and the fixed official tree, not trusted from an old result. source-verification.json records all seven. LICENSE.upstream preserves the pinned repository MIT notice. Source dependencies Radix/cva/lucide are read to understand behavior but are not installed/copied into the runtime; React and ReactDOM come from the parent project's existing fixed dependencies.

## Public contract

`index.d.ts` is the precise public API. Both collections accept text-only items with value/title/content or before/emphasis/after. They do not accept arbitrary HTML. Missing/null content uses structured prose; explicit empty string and explicit undefined preserve empty content. normalizeDisclosureItems is idempotent, including the null sentinel. Duplicate/empty keys are ignored (first duplicate wins).

Tabs value is string|null, Accordion value is readonly string[]. Undefined releases control preserving the last effective selection. defaultValue/defaultOpen are initialization-only. Dynamic invalid selections normalize to the first enabled tab or current source-ordered accordion intersection. Accordion disabled items remain readable if open, but source-style native disabled triggers cannot toggle. Global disabled blocks all collection interaction. Tab roving focus skips disabled entries. No callback fires for programmatic props normalization.

Callbacks are requests. Exact false vetoes an uncontrolled request; controlled state changes only via new value/open props. Parent owner props always render authoritatively even if its callback returns false. A request proposed while controlled is never silently converted to uncontrolled on release. Ordinary metadata does not invalidate a valid uncontrolled request. Requests are finalized in layout after the React parent commit, rechecking current disabled/target restrictions and explicit owner revision. Actual unmount, replacement, newer requests and changed owner cancel obsolete internal proposals. There is no promise-based implicit state acceptance; async owners must hold controlled props.

Keydown handlers for collections ignore prior defaultPrevented, IME/isComposing, keyCode 229 and alt/ctrl/meta/shift modifiers. They implement only their disclosed arrow/Home/End/Enter/Space actions; Tab stays native. Automatic tab focus requests selection once while the intended enabled target still owns focus; arrow navigation invokes that same focus path, not a duplicate request. This preserves synchronous external focus changes. React reconciliation retains unchanged button/span/SVG/path nodes on metadata/long-label/owner updates; no synthetic re-focus is needed. A removed owned focus target gets one enabled current fallback only if no external focus owner took over.

Dialog open/defaultOpen/onOpenChange are boolean. triggerRef references the single rendered trigger (object and callback refs supported). disabled prevents new opens and confirmation; Cancel and native Escape remain reachable while already open. confirmDisabled only disables Continue. onConfirm/onCancel are local action callbacks; exact false keeps the dialog. The actual close is an open-change request. Native cancel is prevented while the controlled request is resolved. Unexpected native close can reopen once after owner refusal; repeating it surfaces an explicit native error instead of an infinite close/focus loop. Environments missing showModal/close surface an error and do not silently claim a modal. onNativeError reports that bounded failure.

Dialog content is absent while closed. Native close/cleanup relinquishes the top layer. An explicit outside focus owner is retained instead of forcing the trigger; otherwise a connected trigger is restored only while no newer external target/other open dialog owns focus. React onConfirm or onOpenChange may update props, close or destroy the component. No onAction runs on unmount. A native showModal focus callback can cause a parent rerender/unmount; the effect checks current mount/operation/node identity and cleanup closes stale native nodes. Real-browser reentrancy is still unverified.

## Form and reset boundary

These three candidates have no editable inputs or form controls with mutable native values. Every rendered button is explicitly type=button, including Dialog Cancel/Continue. They may be nested in an external form without triggering submit/reset, and external form.reset does not change their React selection/open state. There is no fabricated business form submission or promise of form-control reset semantics. This is N/A for editable-field/IME composition reset; the custom key event guard still applies to collection keyboard navigation.

## Styling and verification

All selectors are scoped to .fr7.fr7-disclosure. Transparent text uses --fr-ink/--fr-muted; explicit colored track/open accordion uses --fr-accent with --fr-accent-ink; dialog uses --fr-surface with --fr-ink, and its confirm button explicitly reverses that pair. --fr-line, --fr-radius, --fr-control-radius and --fr-danger are inherited. Shared --fr-bg belongs to the Provider/background; it is deliberately not overwritten by this slice. There are no copied fonts/images. Full long text wraps; native dialog content scrolls within viewport bounds. Focus-visible has ink outline and surface halo. Reduced-motion removes decoration. These are source-level intentions, not a computed color or pixel pass.
